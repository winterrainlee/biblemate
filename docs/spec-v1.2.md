# Bible Reading Mate v1.2 Specification

- 최초 생성일: 2026-01-06
- 최신 수정일: 2026-01-08

## 개요
- **버전**: v1.2.0
- **핵심 목표**: 게스트 모드 도입 및 UX 편의성 강화 (빠른 체감 기능 중심)

## 주요 기능 (Planned)

### 1. 게스트 로그인 (Guest Mode)
- **개념**: 서버 계정 없이 브라우저 로컬 저장소만 사용하여 앱 체험
- **기능 범위**:
  - 로그인 화면에 "게스트로 시작하기" 버튼 추가
  - 로컬 스토리지(LocalStorage)를 활용한 데이터 저장 (하이라이트, 읽기 로그, 노트)
  - 서버 API 호출 차단 (Read-only or Mocked for Guest)
  - 정식 사용자 전환 시 데이터 마이그레이션: v1.1.0에 구현된 **백업(JSON Export) / 복구(JSON Import)** 기능을 활용하여 게스트 데이터를 서버로 이동

### 2. UX 편의성 개선 (Quick Wins)
- **책 변경 시 장 번호 초기화**: 
  - 현재: 장 수가 더 적은 책으로 이동 시 에러 발생 가능성 있음 (예: 시편 150장 -> 요한이서 이동 시 1장이 없어서 로딩 실패)
  - 개선: 책 선택 박스 변경 시 무조건 장 번호를 1장으로 리셋하여 안전한 로딩 보장
- **구절 다중 옵션 팝업**:
  - 본문 구절 클릭 시 즉시 하이라이트/노트 추가/복사 등 옵션을 선택할 수 있는 작은 팝업(Tooltip) 노출
  - **구절 인용 자동 추가**: "노트에 추가" 선택 시 `[책 장:절]` 형식의 텍스트를 자동으로 포함하여 노트 작성 화면으로 연결
- **묵상 템플릿 (Reflection Templates)**:
  - 노트 작성 시 '빈 화면'의 부담을 줄이기 위한 선택적 가이드 제공
  - [템플릿 적용] 버튼 클릭 시 특정 묵상 방법론(예: SOAP - Scripture, Observation, Application, Prayer)에 맞춘 텍스트 가이드를 노트 영역에 삽입
- **동적 세션 만료 정책 (Midnight Session Expiry)**:
  - 보안 및 '매일의 습관' 형성을 위해 로그인한 날의 **자정(00:00:00)**에 세션이 만료되도록 설정
  - 아침 묵상 루틴에 최적화된 정책 (심야 작업 부재 전제)

### 3. 스마트 초기 말씀 로직 (Smart Initial Selection)
- **개요**: 앱 접속 시 말라기 1장이 아닌, 사용자의 맥락에 맞는 구절 자동 로드
- **로직**:
  - 기록이 아예 없는 신규 사용자: **창세기 1장** 로드
  - 기존 사용자: **가장 최신 읽기 기록의 다음 장** 로드
  - **추가**: 사이드바 '오늘의 말씀' 리스트를 **읽은 시간 순(ID순)**으로 정렬하여 표시
- **핵심 가치**: `📊 진도` (연속성 확보)

## 기술적 변경 사항
- 프론트엔드 데이터 서비스 레이어 추상화 (Server API vs LocalStorage 선택적 사용)
- `Content.jsx` 내 구절 클릭 이벤트 핸들러 강화
- `Sidebar.jsx` 내 책 선택 로직 수정
