# 개발 로그 - v2.0

## 개요
- **버전**: v2.0
- **기간**: 2026-01-25 ~ 진행 중
- **목표**: V2.0 UI/UX 개편 및 묵상 시스템 고도화 (구절별 묵상, 묵상일지 분리)
- **주요 변경 요약**:
    - **아키텍처**: DB 스키마 개편 및 구절별 묵상/자유 묵상/기도 테이블 분리
    - **기능**: 통합 네비게이션, 성경 역본(KRV/WEB/BBE) 선택기, 폰트(고딕/명조) 타입 설정, 다중 구절 선택, 서버 설정 동기화, '오늘 읽음' 버튼
    - **UX/디자인**: 3-Column 레이아웃, 모바일 2단 적응형 네비게이션, 하이라이트 레이블 커스텀, 다크 모드 색감 보정 및 스크롤바 일원화

## 주요 기능 및 변경 내역

### 1. Database & Core Management (데이터 및 인프라)
- **DB 스키마 V2/V3 전환**
  - 신규 테이블 추가: `verse_notes`, `free_notes`, `daily_prayers`, `user_settings`
  - 기존 `notes` 데이터를 `free_notes`로 자동 이관하는 마이그레이션 로직 구현
- **백업 및 복구 시스템 고도화**
  - Schema V2/V3 지원: 신규 테이블 및 사용자 설정을 포함한 백업 JSON 구조 업데이트
  - V1 백업 파일 하위 호환성 유지 (Import 시 자동 변환)
  - 무결성 검증 스크립트(`verify_backup.js`) 및 DB 초기화 유틸리티 도입
### 2. Backend API (서버 및 비즈니스 로직)
- **신규 CRUD 엔드포인트**
  - 구절별 묵상 (`/api/verse-notes`): 날짜별/장별 조회 및 UPSERT 지원
  - 자유 묵상 (`/api/free-notes`): 전체 조회 및 날짜별 관리
  - 오늘의 기도 (`/api/prayers`): 날짜별 저장 및 삭제
- **사용자 설정 API (`/api/settings`)**
  - 하이라이트 라벨 등 클라이언트 설정을 서버에 저장하여 기기간 동기화 지원
- **개발 및 보안**
  - 로컬 환경(`localhost`) 인증 예외 처리 추가로 개발 DX 향상
  - Node.js ESM 환경에서의 Dynamic Import 적용으로 실행 순서 제어

### 3. Frontend: Bible Viewer (성경 읽기 핵심 경험)
- **통합 네비게이션 및 레이아웃**
  - 성경/장 선택 및 이전/다음 이동 기능을 뷰어 헤더로 통합
  - 실시간 구절 묵상을 표시하는 **3-Column 레이아웃** 구현 (사이드바 활용)
- **묵상 및 인터랙션 고도화**
  - **다중 구절 선택**: 여러 구절을 한 번에 선택하여 하이라이트 및 묵상 저장 가능
  - **말씀 인용**: 구절 편집 인용 기능 및 사이드바 카드 내 시각적 강조 적용
  - **피드백**: 묵상 완료 구절 빨간 밑줄 및 📝 아이콘 표시
- **'오늘 읽음 표시하기' 기능**
  - 본문 하단에 전용 버튼 추가 및 당일 읽기 여부 실시간 반영
  - 전체 이력(`isCompleted`)과 별개로 당일 액션(`isReadOnCurrentDate`) 상태 관리

### 4. Frontend: Meditation Journal & Apps (묵상일지 및 도구)
- **JournalPage UI 개편**
  - 데스크톱 **20:60:20 비율**의 고정 레이아웃 적용으로 안정성 확보
  - 날짜 표시 형식 개선 ("YYYY년 M월 D일 (요일)") 및 불필요한 요소 제거
- **통계 및 진행도**
  - 구절/자유 묵상 합산 통계 및 이번 달 읽은 책 전체 리스트 표시
  - 읽기표 탭 하단에 **구약/신약 전체 진행도(%)** 바 추가
- **필터링 및 정렬**
  - '실제 작성일' 기준의 묵상 모아보기 및 성경 순서(Asc) 정렬 로직 적용

### 5. UI/UX Polish & Optimization (최적화 및 디자인)
- **모바일/태블릿 최적화**
  - 헤더 탭 명칭 단축 및 로고 아이콘화로 공간 압축
  - 모바일에서 사이드바 자동 숨김 및 1단 본문 보기 전환
  - 구절 팝업 화면 중앙 정렬 강제 및 모바일 전용 '묵상 보기' 버튼 추가
- **디자인 시스템 및 일관성**
  - 하이라이트 라벨(형광펜 이름) 사용자 커스텀 기능 추가
  - 네비게이션 아이콘(`Chevron`) 및 버튼 스타일(투명, 40px) 일원화
  - 완료 버튼 디자인 개선 (Pill-shape, Hover 애니메이션)
- **사용성 개선**
  - 태블릿 브라우저 기본 제스처(`overscroll-behavior`) 차단으로 스크롤 충돌 해결
  - 다크모드/글자크기 아이콘 순서 재배치
  - **스크롤바 스타일 일원화**: 모든 영역에 8px 너비의 테마 대응형 스크롤바 적용
  - **사이드바 레이아웃 최적화**: 스크롤바 위치를 가장자리로 조정하고 내부 여백(1.5rem)을 확보하여 가독성 개선

### 6. Accessibility: Dark Mode Enhancement (다크 모드 고도화)
- **Muted Cobalt 팔레트 도입**
  - 주 색상을 `#2563eb`에서 `#60a5fa`로 변경하여 어두운 배경에서의 눈 피로도 감소
  - 배경색을 `Gray 900 (#111827)` 계열로 조정하여 깊이감 있는 디자인 구현
- **테마 대응형 하이라이트**
  - 하드코딩된 Hex 색상 상수를 CSS 변수(`var(--pk-highlight-*)`)로 전환
  - 기존 저장된 하이라이트 색상 값을 렌더링 시점에 최신 테마 색상으로 자동 변환하는 맵핑 로직 추가
- **성경 역본 및 라이선스 정보**
  - 이용 가능 역본 확정: 개역한글(KRV), WEB, BBE (모두 Public Domain)
  - 설정 페이지 내 역본별 판본 역사 및 저작권 명시 작업 완료

### 7. 추가 기능 (폰트 및 편의성)
- **폰트 스타일 가독성 설정**
  - 고딕(Sans-serif)과 명조(Serif) 중 선택 가능하도록 기능 추가
  - 나눔명조(`Nanum Myeongjo`) 구글 폰트 적용 및 전역 CSS 변수 연동
- **로고 새로고침(Refresh)**
  - 헤더 로고 클릭 시 메인 페이지로 `window.location.href` 호출을 통한 강제 새로고침 적용

## 이슈 및 해결

### [Architecture / Data]
- **ESM 실행 순서 이슈**: 정적 import로 인해 환경 변수 설정 전 모듈이 로드되는 문제 -> **Dynamic Import**(`await import`)로 해결
- **데이터 타입 불일치**: DB(Number)와 API(String) 간 타입 차이로 비교 로직 실패 -> **느슨한 비교(`==`) 또는 형 변환** 적용
- **데이터 분산**: 레거시 `/api/notes`와 신규 `free_notes` 테이블 간 데이터 불일치 -> **라우트 로직 수정 및 데이터 병합** 완료

### [Frontend / UI]
- **레이아웃 붕괴**: Flex 컨테이너 내 자식 요소 확장 누락 및 고정 픽셀 사용 문제 -> **`flex: 1` 및 `%` 단위 비율** 적용
- **이벤트 버버링**: 외부 클릭 감지 로직이 팝업을 즉시 닫는 문제 -> **`e.stopPropagation()`** 추가
- **빈 화면 오류**: 신규 Prop 추가 시 비구조화 할당 누락으로 인한 ReferenceError -> **Destructuring 목록 동기화**로 해결
- **읽기 상태 혼동**: 이력 표시와 오늘 읽기 버튼 기준 차이 -> **`isReadOnCurrentDate` 프로퍼티 신설**로 맥락 분리
- **다크 모드 하이라이트 고정**: `index.css` 수정에도 JS 내 hex 값 사용으로 색상 미변경 -> **CSS 변수 사용 및 매핑 레이어** 도입으로 해결
- **CSS 글로벌 오염**: `.nav-btn` 클래스가 중복 사용되어 모바일에서 묵상일지 레이아웃 침범 -> **Scoping**(`.bible-nav-header .nav-btn`) 적용으로 해결
