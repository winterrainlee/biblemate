# PR: v2.0 묵상일지 UI 개편 및 데이터 통합

## 1. 주요 변경 사항
- **데이터베이스 통합 및 마이그레이션**
  - `bible.db`의 V1 묵상 데이터를 가동 DB(`database.sqlite`)의 `free_notes` 테이블로 병합 (총 12일치 통합 완료)
  - 레거시 `/api/notes`가 신규 `free_notes` 테이블을 참조하도록 서버 로직 수정 (호환성 확보)
- **UI/UX 개선**
  - 헤더 아이콘 순서 재배치 (글자 크기를 다크모드 앞으로 이동)
  - 묵상일지 레이아웃을 20:60:20 황금 비율로 고정 (Flex % 단위 적용)
  - 양측 사이드바 간 컴포넌트 글자 크기 및 일관성 조정
  - 모바일 모드에서의 묵상 블록 좌우 여백(1rem) 추가
