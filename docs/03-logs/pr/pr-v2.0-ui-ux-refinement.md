# PR: v2.0 UI/UX 개선 및 성경 읽기 완료 기능 고도화

## 1. 주요 변경 사항
- **성경 읽기 완료(읽음 표시) 기능 추가**:
  - `BibleViewer.jsx` 하단에 '오늘 읽음 표시하기' 버튼 추가.
  - 당일 읽기 기록이 없는 경우에만 버튼이 활성화되도록 로직 세분화 (`isReadOnCurrentDate`).
- **상태 동기화 및 표시 개선**:
  - 성경 읽기 상태를 '오늘'만이 아닌 '전체 이력' 기준으로 표시하되, 날짜를 병기하여 가독성 향상.
  - 읽기표-성경뷰어 간 장 번호(Number vs String) 타입 불일치로 인한 동기화 오류 수정.
- **성경 읽기 뷰어 레이아웃 최적화**:
  - 사이드바 내 중복 헤더 제거 및 네비게이션 헤더 디자인(가운데 정렬, Pill-shape 버튼) 개선.
  - 가로 모드/태블릿에서 3단 레이아웃(묵상-본문-묵상) 최적화.
- **모바일 UX 고도화**:
  - 헤더 탭 명칭 단축 및 불필요한 아이콘 숨김으로 공간 확보.
  - 모바일 구절 팝업 중앙 정렬 및 묵상 바로보기 기능 추가.
- **다국어 및 날짜 처리**:
  - 날짜 형식에 소괄호 추가 및 `created_at` 기반 묵상 정렬 구현.
