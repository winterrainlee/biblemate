# PR: v1.3.1 성경 텍스트 무결성 확보 및 구조적 오류 수정

## 📌 개요
이 PR은 성경 데이터의 신뢰성을 확보하기 위한 긴급 수정(Hotfix) 및 데이터 정제 작업을 포함합니다. 
개역한글(KRV) 텍스트 전반에 걸쳐 발견된 문자 깨짐(`\uFFFD`) 현상을 근본적으로 해결하고, 욥기 등에서 발견된 심각한 구조적 오류(병합 사고)를 복구했습니다.

## 변경된 기능
### 1. 데이터 정제 (Data Cleaning)
- **문자 깨짐(\uFFFD) 해결**:
  - `import-bible.js`의 네트워크 수신 로직을 `Buffer` 기반으로 재설계하여, 멀티바이트(한글) 문자가 청크 경계에서 손상되는 문제 해결.
  - 전체 DB 전수 검사 결과 **Corrupted 0건** 달성.
- **HTML 엔티티 제거**:
  - `&#x27;`, `&quot;` 등 웹 인코딩 잔재를 디코딩 로직을 통해 모두 복원.

### 2. 구조적 오류 복구 (Structural Fix)
- **욥기 35:16 ~ 42장 복원**:
  - 원본 데이터 병합으로 인해 7개 장(Chapter) 전체가 꼬여있던 문제를 확인.
  - 대한성서공회 원문 203개 구절을 확보하여 `bible-corrections.json`을 통해 전면 교체.
- **누락 데이터 복구 로직**:
  - `UPDATE` 대신 `INSERT OR REPLACE` 구문을 도입하여, 병합 사고로 인해 DB에 아예 존재하지 않았던 구절들도 정상적으로 생성되도록 개선.

### 3. 패치 시스템 고도화
- **Corrections System**:
  - 총 **517개** 구절에 대한 수정을 담은 `bible-corrections.json` 적용.
  - 향후 유지보수를 위해 원본 소스 수정 대신 '오버라이딩 패치' 방식 정립.
