# PR: Multi-Verse Selection (다중 구절 선택 및 묵상)

## 📌 개요
- **Feature Check**: #MultiSelect
- 말씀 집중 모드에서 여러 구절을 선택하여 하이라이트를 적용하거나, 범위를 지정하여 묵상 노트를 작성할 수 있는 기능을 구현했습니다.

## 🛠 변경 사항

### Database
- **Schema Update**: `verse_notes` 테이블에 `verse_range` 컬럼 추가 (`TEXT`, Nullable)
- **Migration**: 로컬 DB (`bible.db`)에 `ALTER TABLE` 적용 완료

### Backend (Server)
- `POST /api/verse-notes`: `verse_range` 파라미터 수신 및 DB 저장 로직 추가

### Frontend (Client)
- **BibleViewer.jsx**:
  - `selectedVerses` 상태 추가 (배열)
  - 구절 클릭 시 다중 선택/해제 토글 로직 구현 (팝업 열린 상태에서)
  - 하이라이트 팔레트 클릭 시 선택된 모든 구절에 색상 적용
  - 묵상 저장 시 선택된 구절 범위를 포맷팅(예: "5-6, 9")하여 서버로 전송
  - 사이드바 노트 카드에 구절 범위 표시
  - 선택된 구절에 시각적 효과(배경색/테두리) 적용
  - **UI 개선**: 팝업 메뉴 너비 확장 및 반응형 스타일 적용, 닫기 버튼 추가
- **Auth (Hotfix)**:
  - 로컬 개발 환경(`localhost`, `127.0.0.1`)에서는 암호 인증을 건너뛰도록 미들웨어 수정

## 📸 검증 방법 (테스트 시나리오)
1. **다중 선택**:
   - 구절 하나를 클릭하여 팝업을 띄웁니다.
   - 팝업이 떠 있는 상태에서 다른 구절들을 클릭합니다.
   - 선택된 구절들이 파란색 배경으로 표시되는지 확인합니다.
2. **범위 하이라이트**:
   - 여러 구절을 선택한 상태에서 하이라이트 색상(예: 노랑)을 클릭합니다.
   - 선택된 모든 구절이 노란색으로 칠해지는지 확인합니다.
3. **범위 묵상**:
   - 여러 구절(떨어진 구절 포함)을 선택하고 묵상 버튼을 누릅니다.
   - 묵상을 작성하고 저장합니다.
   - 사이드바에 카드가 생성되고 `[성경책] [장]:[시작절]-[끝절], [다른절]` 형태의 범위가 표시되는지 확인합니다.
4. **선택 취소**:
   - 팝업의 X 버튼을 누르거나 빈 공간(또는 ESC)을 눌러 선택이 모두 해제되는지 확인합니다.
