# Walkthrough v2.1.4 - 개별 구절 묵상 복사

## 변경 요약
- 묵상일지와 성경읽기 모드의 구절별 묵상 카드에 개별 복사 아이콘을 추가했다.
- 개별 복사는 묵상 내용만 클립보드에 저장한다.
- 전체 묵상 복사와 개별 묵상 복사가 동일한 클립보드 fallback 로직을 사용하도록 정리했다.
- 성경읽기 모드 좌/우 사이드바와 모바일 묵상 보기 팝업에서도 같은 액션 순서와 피드백을 사용한다.

## 검증 결과
- [x] `client` 빌드 성공
- [x] 복사 아이콘이 수정 아이콘 앞에 배치됨
- [x] 성경읽기 모드 좌/우 묵상 카드와 모바일 묵상 보기 팝업에 복사 아이콘 노출
- [x] 복사 성공 시 클릭한 카드만 `Check` 아이콘으로 전환됨
- [x] 수정 모드에서는 카드 액션 아이콘이 숨겨짐
- [x] 백엔드 API 및 DB 변경 없음

## 수동 확인 메모
- 클립보드 텍스트는 `note.content`만 사용한다.
- 모바일 Safari 대응을 위해 기존 `textarea + execCommand('copy')` fallback을 유지했다.
