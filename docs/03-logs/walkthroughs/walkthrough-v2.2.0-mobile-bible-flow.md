## 1. 구현 요약

### MOB-101. 모바일 성경 상단 압축

- 모바일에서 기존 역본/책/장 select 묶음 대신 compact context bar를 노출한다.
- compact bar는 `오늘 이어 읽기 · 책 장`과 현재 역본을 한 줄에 보여준다.
- compact bar를 탭하면 역본/책/장 native select가 들어 있는 바텀시트를 연다.
- 데스크탑/태블릿의 기존 select 기반 네비게이션은 유지한다.

### MOB-102. 구절 액션 바텀시트

- 모바일에서 구절 선택 팝업은 하단 바텀시트로 표시한다.
- 구절 액션 순서를 `묵상하기` → `묵상 보기` → `하이라이트` → `구절 복사`로 재정렬했다.
- 다중 구절 선택 중에는 `n개 구절 선택됨`으로 선택 상태를 표시한다.
- 📝 아이콘을 누르면 일반 메뉴가 아니라 해당 구절 묵상 보기로 바로 들어간다.
- 구절 복사는 HTTP/LAN 환경에서도 동작하도록 clipboard fallback을 추가했다.

### MOB-103. 구절 묵상 작성 전체 화면

- 모바일 작성 모드는 전체 화면 오버레이로 표시한다.
- 사용자가 선택한 말씀 본문을 작성 화면 상단에 항상 표시한다.
- 말씀 인용 포함 옵션은 기본 활성화 상태로 시작한다.
- 저장/취소 액션은 safe-area를 고려한 하단 영역에 유지한다.
- 작성 중 닫기 시 내용 유실 확인을 띄운다.

### MOB-104. 현재 장 묵상 모바일 복구

- 모바일 성경 화면 상단에 `이 장의 묵상 n개 보기` 버튼을 추가했다.
- 버튼을 누르면 현재 장의 모든 구절 묵상을 바텀시트로 볼 수 있다.
- 묵상 카드의 구절 ref를 누르면 본문 해당 구절로 스크롤하고 시트를 닫는다.

### MOB-105. 하단 읽기 action bar

- 모바일 하단에 `이전`, `오늘 읽음 표시`, `다음` action bar를 추가했다.
- 읽음 완료 상태에서는 중앙 버튼이 `묵상일지 보기`로 바뀐다.
- 기존 본문 하단 읽음 버튼은 모바일에서 숨겨 중복을 줄였다.
- action bar는 safe-area 위에 고정된다.

## 2. 검증 결과

### 자동 검증

```bash
cd client
npm run lint
```

결과: 성공. PR-B 시점에 남아 있던 hook dependency warning 6개는 v2.2 통합 정리에서 해소했다.

```bash
cd client
npm run build
```

결과: 성공.

### 로컬 HTTP 검증

검증 환경:
- API 서버: `http://127.0.0.1:3001`
- Vite 클라이언트: `http://127.0.0.1:5173`

확인 결과:
- `http://127.0.0.1:5173/`가 정상 HTML을 반환한다.
- `http://127.0.0.1:5173/api/health`가 정상 응답한다.
- `http://127.0.0.1:5173/api/bible/Gen/1?version=krv`가 본문 데이터를 반환한다.

### 제한 사항

- 이번 검증 중 인앱 브라우저 `iab` 연결이 제공되지 않아 Playwright 기반 시각 검증은 수행하지 못했다.
- 실제 iPhone Safari 수동 QA는 2026-06-12 사용자 검증으로 통과했다.
