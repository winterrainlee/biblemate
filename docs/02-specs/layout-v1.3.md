# UI/UX Layout Plan v1.3

> **Last Updated: 2026-01-08**

v1.3.0 기준의 최신 레이아웃 설계입니다.
기존 v1.0 대비 **로그인 페이지(보안)**, **설정 페이지(세부 옵션)**, 그리고 **모바일/데스크톱 반응형 구조**가 고도화되었습니다.

## 1. 페이지 구조 (Sitemap)

- **Login Page**: 암호 입력 및 진입
- **Main Layout (Dashboard)**:
  - **Sidebar (Left)**: 달력, 오늘의 말씀(NotePreview), 성경 선택
  - **Content (Right)**: 성경 본문 Viewer, 노트 에디터 Editor
- **Settings Page**: 테마, 폰트, 데이터 관리(백업/복원), 초기화
- **Reading Table**: 전체 성경 읽기표 현황 (Modal/Page)

## 2. 상세 레이아웃

### 2.1 로그인 페이지 (Login)
앱 최초 진입 시 또는 세션 만료 시 표시됩니다.

```
┌───────────────────────────────────────┐
│                                       │
│          📖 Bible Mate                │
│                                       │
│       [ 🔒 비밀번호 입력 ]            │
│           [ 로그인 ]                  │
│                                       │
│   (초기 비밀번호: biblemate)          │
│                                       │
└───────────────────────────────────────┘
```

### 2.2 메인 대시보드 (Main Dashboard)

2-Column 구조로, 좌측은 탐색/기록, 우측은 읽기/쓰기에 집중합니다.
구현된 실제 순서: **달력 → 오늘의 말씀/노트 프리뷰 → 성경 선택**

```
┌顶部 Header ─────────────────────────────────────────────── [⚙️설정] ─┐
│ 📖 Bible Reading Mate                                              │
├────── Sidebar (300px) ─────┬─────── Content Area (Flexible) ───────┤
│                            │                                       │
│  [📅 달력 (Calendar)]      │  [ 📖 성경 본문 뷰어 ]              │
│   < 2026. 01 >             │  창세기 1장                         │
│  [ 1  2  3  4  5 ]         │                                     │
│  (읽은 날짜 표시)           │  1 태초에 하나님이...               │
│                            │  (스크롤 영역)                      │
│  ────────────────────────  │                                     │
│                            │  (구절 클릭 시 팝업 액션)           │
│  [� 오늘의 말씀 (Preview)] │                                     │
│  📖 창세기 1                │                                     │

│  ────────────────────────  │  [ 📝 묵상 에디터 (Editor) ]        │
```

### 2.3 성경 읽기표 (Reading Table Activity)
전체 66권의 읽기 현황을 한눈에 보는 그리드 뷰입니다.
설정 또는 헤더의 아이콘을 통해 진입합니다.

```
┌──────────────────────────────────────────┐
│ 📊 성경 읽기표                 [X 닫기]  │
├──────────────────────────────────────────┤
│ [구약 (Old Testament)]                   │
│ 창 [1][2][3][4]...                       │
│ 출 [1][2][3]...                          │
│ ...                                      │
│                                          │
│ [신약 (New Testament)]                   │
│ 마 [1][2][3]...                          │
│ ...                                      │
└──────────────────────────────────────────┘
```

## 3. 디자인 시스템 (Design System) v1.3

### Colors (Palette)
- **Primary**: `#4A5568` (Slate Gray)
- **Accent**: `#3182CE` (Blue)
- **Background**: Light(`#FFFFFF`) / Dark(`#1A202C`)

### Components
- **Card**: Rounded-lg, Soft Shadow
- **Editor Buttons**:
    - **Primary**: `[📄 양식]` (Text + Icon)
    - **Icon Only**: `[💾]`, `[🗑️]` (Clean look)
    - **Secondary**: `[📋 복사]` (Text + Icon)
