## 주요 구현 기능

### 1. R1: 읽기 완료 버튼 개선

#### 문제
- 현재 버튼 클릭 시 피드백이 불명확하고, 중복 클릭 시 중복 로그가 쌓일 위험이 있음.

#### 해결
- **버튼 상태 관리**: `idle` (기본), `loading` (통신 중), `success` (완료), `already_logged` (이미 읽음)
- **피드백**: 성공/실패 시 전역 Toast 메시지 표시
- **중복 방지**:
  - 클라이언트: "오늘 읽음" 상태면 버튼 비활성화 또는 "완료됨" 표시
  - 서버: (선택) 동일 `date`, `book`, `chapter` 요청 시 중복 무시 또는 409 처리 (v1.4.0에서는 클라이언트 위주 방어)

---

### 2. R2: 성경 읽기표 UI 개선 (페이지화)

#### 문제
- 모바일에서 모달(Popup)로 1189장을 표시하기에 공간이 협소하고 답답함.

#### 해결
- **전용 라우트 신설**: `/chart` (또는 `/attendance`)
- **UI 구조**: 헤더(뒤로가기 포함) + 본문(전체 읽기표) + 바닥글(통계 등)
- **UX**:
  - 헤더의 아이콘 클릭 시 모달 대신 `/chart` 페이지로 이동
  - 브라우저 Back 버튼으로 자연스러운 복귀
  - (권장) 쿼리 파라미터 지원 고려 (예: `/chart?filter=ot`)

---

### 3. R4: 화면 분할 비율 조정

#### 문제
- Reading/Notes 분할 비율이 고정되어 있어, 묵상 노트 작성 시나 모바일 환경에서 불편함.

#### 해결
- **드래그 리사이저**: 두 영역 사이에 핸들(Bar) 제공, 드래그로 높이/너비 조절
- **비율 저장**: `localStorage`에 `splitRatio` (예: `50:50`) 저장 및 초기 로드 시 복원
- **최소/최대 제한**: 한쪽 영역이 완전히 사라지지 않도록 최소 20% 등 제한 (단, "집중 모드"는 예외 처리)

---

### 4. N1: 프로덕션 CORS Allowlist

#### 문제
- `origin: true` 설정은 보안상 취약할 수 있음.

#### 해결
- **환경 변수**: `ALLOWED_ORIGINS` (예: `https://biblemate.fly.dev,http://localhost:5173`)
- **Middleware**: 요청 Origin이 Allowlist에 없으면 CORS 에러 반환
- **Dev/Prod 분기**: 로컬 개발 시 편의성을 위해 유연한 설정 가능하되, Prod는 엄격 적용
