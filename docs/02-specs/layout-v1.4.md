# UI/UX Layout Plan v1.4

> **Last Updated: 2026-01-12**

v1.4.0 기준의 최신 레이아웃 설계입니다.
기존 v1.3 대비 **성경 읽기표 페이지화(/chart)**, **화면 분할 리사이저**, **버튼 스타일 개선**이 추가되었습니다.

## 1. 페이지 구조 (Sitemap)

- **Login Page**: 암호 입력 및 진입
- **Main Layout (Dashboard)**:
  - **Sidebar (Left)**: 달력, 오늘 읽은 말씀(NotePreview), 성경 선택
  - **Content (Right)**: 성경 본문 Viewer, 노트 에디터 Editor (Split View)
- **Settings Page**: 테마, 폰트, 데이터 관리, 화면 설정(ON/OFF)
- **Bible Chart Page**: 성경 읽기표 전체 현황 및 필터링 (Page)

## 3. 디자인 시스템 (Design System) v1.4

### New Components
- **Round Pill Button**: 읽기 완료 버튼이 둥근 알약 형태로 변경되었습니다.
    - Default: `var(--pk-color-bg-secondary)` / Text: "읽기 완료"
    - Active: `var(--pk-color-success)` / Text: "✓ 완료함"
- **Split Resizer**:
    - Width: 12px
    - Cursor: `col-resize`
    - Hover: 회색 배경 강조
- **Stat Filter Tabs**:
    - Active: Primary Color + Bold
    - Inactive: Gray Text
