# BibleMate v2.3 Specification - Visual Redesign

- 작성일: 2026-06-12
- 기준 제안서: `docs/01-planning/proposal-visual-redesign.md`
- 목표 버전: v2.3.0
- 상태: 준비 완료 / 구현 승인 대기

---

## 1. 개요

v2.3.0은 BibleMate의 기능 구조를 유지한 채, 시각 언어를 "관리용 SaaS 대시보드"에서 "나만의 서재에서 읽는 성경"으로 전환하는 Minor Release다.

핵심 목표는 아래 4가지다.

1. 파란 업무용 UI 팔레트를 따뜻한 종이/잉크/가죽 계열 팔레트로 교체한다.
2. 성경 본문을 세리프 중심의 독서 표면으로 만들고, UI 도구와 본문 위계를 분리한다.
3. 묵상 카드와 입력 화면을 알림 박스가 아니라 여백 메모와 기도 노트처럼 보이게 한다.
4. 기능 중심 마이크로카피를 묵상 흐름에 맞는 존댓말 문장으로 정리한다.

## 2. 범위

### 포함

- 전역 디자인 토큰 교체: 라이트/다크 색상, border, shadow, radius, highlight palette.
- 신규 표면 토큰 추가: `--pk-color-bg-elevated`.
- 본문 기본 글꼴을 `Noto Serif KR`로 전환하고, 설정에서 `Noto Serif KR` / `Gowun Batang` / `Noto Sans KR` 선택을 제공.
- 성경 읽기 화면의 본문 폭, 여백, 절 번호, hover, 컬럼 구분선, paper surface 조정.
- 묵상 카드, 노트 에디터, 묵상일지의 색상/테두리/타이포그래피 정합.
- 헤더 시각 무게 축소와 아이콘 중심 컨트롤 정리.
- 로그인 페이지 첫인상 리디자인.
- 파비콘/앱 아이콘을 v2.3 팔레트와 서재 컨셉에 맞게 리디자인.
- 대시보드, 읽기표, 캘린더, 차트 색상 팔레트 정합.
- 제안서 §3.4 기준 마이크로카피 교체.

### 제외

- DB 스키마 변경.
- API 계약 변경.
- 성경/묵상/읽기표의 기능 동작 변경.
- 모바일 바텀시트, safe-area, 전체 화면 묵상 작성 등 v2.2 UX 구조 변경.
- 상단 select 3개를 제목형 컨트롤 하나로 압축하는 네비게이션 재설계.
- 가죽 텍스처, 책장 그래픽 등 강한 스큐어모피즘.
- 종이 노이즈 텍스처는 선택 항목으로 보류한다. 구현 중 별도 승인 없이는 적용하지 않는다.

| 토큰 | 값 | 용도 |

| `--pk-color-text` | `#3D3529` | 기본 잉크 텍스트 |
| `--pk-color-text-secondary` | `#8A7E6D` | 보조 텍스트 |
| `--pk-color-primary` | `#8B5E3C` | 가죽 갈색, 주요 액션 |

| 토큰 | 값 | 용도 |
|---|---:|---|
| `--pk-color-bg` | `#211C16` | 따뜻한 흑갈색 배경 |
| `--pk-color-bg-secondary` | `#2B251D` | 주변 표면 |

## 4. 타이포그래피 기준

- 성경 본문 기본값: `Noto Serif KR`, 줄간격 1.9~2.0, `word-break: keep-all`.
- 선택 가능한 본문 글꼴: `Noto Serif KR`, `Gowun Batang`, `Noto Sans KR`.
- UI 글꼴: 기존 산세리프 유지.
- 절 번호: 작은 세리프, tertiary 텍스트 색, 위첨자 느낌.
- 장 제목/본문 네비게이션: 세리프 700 중심.
- 한글 faux italic은 제거한다.
- 인용구는 본문 세리프 변수를 따르고, 크기와 줄간격을 상향한다.

## 5. 화면별 기준

| 화면 | 변경 기준 |
|---|---|
| 성경 읽기 | 본문이 첫 시각적 주인공이 되도록 paper surface, 읽기 폭, 여백, 절 번호, hover를 조정 |
| 묵상 카드 | 파란 left-border와 알림 박스 느낌을 제거하고 미색 메모지 문법 적용 |
| 묵상일지 | "데이터 목록"보다 하루의 기도 노트처럼 보이도록 표면, 빈 상태, 섹션 문구 정리 |
| 헤더 | 파란 로고/탭 강조를 잉크/가죽색으로 교체하고 조작 장치의 시각 무게 축소 |
| 로그인 | 크림 배경, 세리프 환영 문구, 성경 구절 한 줄로 첫인상 정리 |
| 파비콘/앱 아이콘 | `/logo.png` 기반 브라우저 탭과 apple touch icon을 새 팔레트에 맞춘 단순 실루엣으로 교체 |
| 읽기표/차트/캘린더 | 색상만 v2.3 팔레트에 맞추고 기존 기능/구조 유지 |

## 6. 마이크로카피 기준

| 현재 | v2.3 기준 |
|---|---|
| 읽기 완료 | 오늘의 말씀을 마쳤습니다 |
| 읽은 말씀 | 오늘 펼친 말씀 |
| 구절별 묵상 | 마음에 머문 구절 |
| 오늘의 기도 | 기도로 마무리 |
| 작성된 묵상이 없습니다 | 아직 남긴 묵상이 없어요 |
| 전반부 묵상이 없습니다 | 아직 앞부분에 남긴 묵상이 없어요 |
| 묵상하기 | 이 말씀 묵상하기 |
| 구절 복사 | 말씀 복사 |
| 전체 진도 | 말씀 여정 |
| 다음 안 읽은 장 읽기 | 다음 말씀 이어 읽기 |

원칙: 사용자 대상 문구는 존댓말 어미로 통일한다.

## 7. 수용 기준

1. 성경 읽기 첫 화면에서 본문이 조작 UI보다 먼저 보인다.
2. 라이트/다크 모두 Tailwind Blue 기반 SaaS 인상이 사라진다.
3. 묵상 카드가 대시보드 카드가 아니라 여백 메모처럼 보인다.
4. 구절 액션 팝업에서 `이 말씀 묵상하기`가 1순위 행동으로 보인다.
5. 묵상일지가 데이터 목록이 아니라 하루의 기도 노트처럼 보인다.
6. 다크모드는 개발자 테마가 아니라 밤에 말씀을 읽는 공간처럼 보인다.
7. 파비콘과 홈 화면 아이콘이 v2.3 컨셉과 일관되며, 16px/32px/180px 기준에서 뭉개지지 않는다.
8. 일반 텍스트는 WCAG AA 4.5:1, 큰 텍스트는 3:1 기준을 통과한다.
9. v2.2 모바일 UX 구조와 데스크톱 3컬럼 경험은 회귀하지 않는다.

## 8. 검증 기준

- `cd client && npm run lint`
- `cd client && npm run build`
- 라이트/다크 × 데스크톱/모바일 4조합 스크린샷 점검
- 성경 본문, secondary 텍스트, primary 버튼, focus ring 대비 확인
- 하이라이트 4색 위 텍스트 가독성 확인
- 파비콘/앱 아이콘의 브라우저 탭, 북마크, iOS 홈 화면 표시 확인
- v2.2 모바일 핵심 흐름 회귀 확인
  - safe-area
  - 바텀시트
  - 전체 화면 묵상 작성
  - 하단 action bar
  - 모바일 `Aa` 본문 설정
