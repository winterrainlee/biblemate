# Project Spec v2.3.2 - Mobile Verse Selection & Login Copy Hotfix

- 작성일: 2026-06-28
- 상태: 배포 준비
- 유형: Patch hotfix

## 1. 목적

v2.3.2는 모바일 성경 읽기 화면에서 구절 선택 중 사용할 수 있는 세로 공간을 늘리고, 로그인 화면의 말씀 문구에 정확한 출처를 제공하는 patch hotfix다.

## 2. 요구사항

- 모바일 성경 헤더는 책/장/역본 선택과 읽음 상태를 한 행에서 확인할 수 있어야 한다.
- 모바일 보조 액션인 `이 장의 묵상 보기`와 `Aa`는 같은 행에 배치되어 헤더 높이를 줄여야 한다.
- 구절 선택 팝업이 표시되는 동안 모바일 헤더와 하단 읽기 액션 바는 선택 UI를 가리지 않아야 한다.
- 구절 선택 팝업은 safe-area와 헤더 높이를 고려해 화면 안에 표시되어야 한다.
- 로그인 페이지의 말씀 문구는 `주의 말씀은 내 발에 등이요` / `내 길에 빛이니이다` 두 줄과 `(시편 119:105)` 출처를 표시해야 한다.

## 3. 비기능 요구사항

- 기존 데스크톱 성경 읽기 레이아웃은 변경하지 않는다.
- 기존 모바일 책/장/역본 선택 동작은 유지한다.
- 로그인 인증 로직은 변경하지 않는다.
- `.claude/` 로컬 작업 파일은 Git 추적 대상에서 제외한다.

## 4. 수용 기준

- 모바일에서 구절 선택 팝업 표시 중 헤더와 하단 액션 바가 접혀 선택 공간이 확보된다.
- 모바일 기본 읽기 상태에서는 책/장/역본, 읽음 상태, 묵상 보기, 글자 설정 진입점이 모두 접근 가능하다.
- 로그인 화면에 시편 119:105 출처가 별도 스타일로 표시된다.
- v2.3.2 버전 표기가 package, README, 설정 화면, 문서에 반영된다.
