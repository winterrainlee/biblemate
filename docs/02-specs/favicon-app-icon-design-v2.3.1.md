# Favicon & App Icon Design Guidelines v2.3.1

## 1. 이미지 해석 요약

Gemma E4B는 현재 아이콘을 아래처럼 해석했다.

- 전체 주제는 따뜻한 갈색 배경 위에 놓인 미니멀한 열린 성경책이다.
- 왼쪽 페이지의 작은 십자가가 기독교/성경 앱의 정체성을 직접 전달한다.
- 오른쪽 페이지의 짧은 붉은 가로선은 본문 또는 기록된 말씀을 암시한다.
- 가운데의 탄색 책등/책갈피 형태가 양쪽 페이지를 묶고, 열린 책의 구조를 유지한다.
- 크림색 페이지, 갈색 배경, 탄색 책갈피, 붉은 본문선이 v2.3의 Paper & Ink / Candlelight 팔레트와 잘 맞는다.
- 구도는 중앙 정렬이고, 책이 프레임의 큰 비중을 차지해 홈 화면 아이콘에서는 즉시 알아보기 쉽다.

## 2. 기준 컬러 팔레트

현재 아이콘은 BibleMate v2.3 팔레트를 압축한 브랜드 자산으로 다룬다. 향후 아이콘을 다시 만들거나 리샘플링할 때는 아래 색상값을 기준으로 삼는다.

| 요소 | 색상 | HEX | 역할 |
|---|---|---:|---|
| 전면 배경 | 가죽 갈색 | `#8B5E3C` | 앱의 따뜻한 서재 톤, 브라우저 탭에서 가장 먼저 보이는 브랜드 면 |
| 성경 페이지 | 밝은 종이색 | `#FFFAF2` | 열린 말씀의 주 표면, 작은 크기에서 책 실루엣을 만드는 핵심 대비 |
| 책갈피 | 촛불 금색 | `#C9A36B` | 이어 읽기와 묵상 흐름을 암시하는 따뜻한 강조색 |
| 묵상 밑줄 | 벽돌색 | `#A4543F` | 본문 위에 머문 생각, 기록, 강조를 암시하는 보조 포인트 |
| 페이지 골과 구절선 | 가죽 갈색 | `#8B5E3C` | 배경과 같은 잉크색 계열로 페이지 구조를 단순하게 유지 |

색상 우선순위는 성경 페이지의 `#FFFAF2`와 전면 배경의 `#8B5E3C` 대비를 가장 먼저 지키고, 그 다음 책갈피 `#C9A36B`, 묵상 밑줄 `#A4543F` 순서로 조정한다.

## 3. 디자인 의도

이 아이콘은 장식적 로고보다 "말씀을 펼친 공간"을 먼저 보여준다. BibleMate의 첫인상은 기능형 성경 도구가 아니라 개인 서재에서 성경을 펴고 묵상하는 경험이어야 한다.

핵심 상징은 세 가지다.

| 요소 | 의미 | 유지 이유 |
|---|---|---|
| 열린 성경 | 읽기와 묵상 | 앱의 핵심 행동을 가장 직접적으로 설명 |
| 십자가 | 기독교 정체성 | 작은 크기에서도 Bible 앱임을 빠르게 식별 |
| 책갈피/책등 | 이어 읽기, 개인 기록 | BibleMate의 읽기 흐름과 기록성을 암시 |

## 4. 제작 원칙

### 유지해야 할 것

- 정사각형 캔버스와 중앙 정렬 구도를 유지한다.
- 배경은 가죽 갈색 `#8B5E3C`를 유지해 v2.3 팔레트와 연결한다.
- 책 페이지는 밝은 종이색 `#FFFAF2`로 두어 배경과 명확히 분리한다.
- 책갈피는 촛불 금색 `#C9A36B`를 사용해 따뜻한 강조점을 만든다.
- 묵상 밑줄은 벽돌색 `#A4543F`로 제한해 작은 크기에서도 과한 장식이 되지 않게 한다.
- 페이지 골과 구절선은 배경과 같은 `#8B5E3C` 계열로 처리해 전체 형태를 단순하게 유지한다.
- 십자가는 작은 크기에서도 사라지지 않도록 단순한 형태와 충분한 두께를 유지한다.
- 책갈피 또는 책등은 열린 책의 구조를 읽게 하는 핵심 요소로 유지한다.
- 그림자와 입체감은 부드럽게 쓰되, 16px에서 형태를 흐릴 정도로 복잡하게 만들지 않는다.

### 피해야 할 것

- 세부 본문선을 많이 늘리지 않는다. 작은 파비콘에서는 장식 막대로 보일 수 있다.
- 실제 텍스트, 약자, 긴 문구를 넣지 않는다.
- 배경에 질감, 그라데이션, 책장/촛불 같은 추가 장면을 넣지 않는다.
- 십자가와 본문선의 색을 지나치게 약하게 만들지 않는다.
- 앱 화면 UI 색상과 동떨어진 파랑/초록 중심 팔레트로 되돌리지 않는다.

## 5. 크기별 기준

| 크기 | 용도 | 기준 |
|---:|---|---|
| 16×16 | 브라우저 탭 favicon | 열린 책의 흰 형태와 갈색 배경 대비가 먼저 보여야 한다. 십자가/본문선은 보조 요소로 허용한다. |
| 32×32 | 브라우저/북마크 favicon | 십자가와 책갈피가 구분되어야 한다. 붉은 본문선은 두 줄 이하처럼 단순하게 보여야 한다. |
| 48×48 | `.ico` 고해상도 엔트리 | 책의 좌우 페이지와 중앙 책등이 명확해야 한다. |
| 180×180 | iOS home screen | 둥근 아이콘 마스크 안에서도 책이 잘리지 않아야 한다. |
| 192×192 / 512×512 | PWA install icon | maskable icon으로 잘릴 수 있으므로 가장자리에는 충분한 갈색 여백을 둔다. |

## 6. 검증 체크리스트

- `favicon.ico` 내부에 16/32/48 엔트리가 포함되어 있는가?
- 16px에서 책의 외곽이 배경과 분리되는가?
- 32px에서 십자가와 책갈피가 서로 뭉개지지 않는가?
- iOS/Android 홈 화면 마스크에서 책 모서리나 책갈피가 잘리지 않는가?
- `client/index.html`이 `.ico`, 16/32 PNG, `apple-touch-icon`을 모두 참조하는가?
- `client/public/manifest.json`이 192/512 PNG를 참조하는가?
- 로그인 화면, 브라우저 탭, 홈 화면 아이콘이 같은 이미지 계열로 보이는가?

## 7. E4B 기반 주의점

Gemma E4B는 현재 이미지의 균형과 상징성은 강점으로 보면서도, 작은 크기에서 아래 위험을 확인해야 한다고 제안했다.

- 크림색 페이지와 갈색 배경의 경계가 아주 작은 크기에서 흐려질 수 있다.
- 오른쪽 페이지의 붉은 선은 16px에서는 "본문"보다 단순 장식 막대로 보일 수 있다.
- 따라서 향후 아이콘을 다시 만들 때는 본문선보다 책 실루엣, 십자가, 책갈피를 우선순위로 둔다.

## 8. 향후 수정 방향

새 아이콘을 다시 제작해야 한다면 아래 순서를 따른다.

1. 먼저 1024×1024 대표 이미지를 만든다.
2. 16/32/48/180/192/512 크기로 리샘플링한다.
3. 16px와 32px에서 형태가 무너지면 본문선 디테일을 줄이고, 책 외곽과 십자가 두께를 우선 조정한다.
4. HTML/manifest 연결을 확인한다.
5. 실제 브라우저 탭과 모바일 홈 화면에서 표시를 확인한다.
