# Project Spec v2.3.3 - Auto Read from Verse Note

- 작성일: 2026-07-07
- 상태: 배포 준비
- 유형: Patch UX/data consistency

## 1. 목적

v2.3.3은 사용자가 특정 장의 구절별 묵상을 저장하면 해당 날짜의 해당 장을 자동으로 읽음 처리해, 묵상 기록과 읽기 기록이 어긋나는 일을 줄이는 patch다.

## 2. 요구사항

- 구절별 묵상 저장이 성공하면 동일 `date + book + chapter`의 읽기 기록이 자동 생성되어야 한다.
- 이미 해당 날짜/책/장을 포함하는 읽기 기록이 있으면 중복 생성하지 않아야 한다.
- 성경 읽기 화면에서 묵상 저장 후 완료 상태가 즉시 갱신되어야 한다.
- 수동 `오늘의 말씀 완료` 및 읽음 취소 흐름은 기존처럼 유지되어야 한다.

## 3. 비기능 요구사항

- 자유 묵상과 기도 저장은 읽음 자동 처리 대상이 아니다.
- 구절 묵상 삭제는 읽음 기록 자동 삭제를 유발하지 않는다.
- 기존 백업/복원 스키마는 변경하지 않는다.
- 읽기 기록의 장 범위(`chapter_from`, `chapter_to`)가 현재 장을 포함하면 해당 장을 읽은 것으로 판단한다.

## 4. 수용 기준

- 새 구절 묵상 저장 후 `reading_logs`에 동일 날짜/책/장 기록이 추가된다.
- 같은 묵상을 다시 저장해도 읽기 기록은 하나만 유지된다.
- 성경 읽기 화면의 `오늘의 말씀 완료` 상태가 묵상 저장 직후 갱신된다.
- package, README, 설정 화면, 문서에 v2.3.3 버전 표기가 반영된다.
