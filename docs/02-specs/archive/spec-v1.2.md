## 주요 구현 기능 (Implemented)

### 1. UX 편의성 개선
- **책 변경 시 장 번호 초기화**: 
  - 책 선택 박스 변경 시 장 번호를 1장으로 자동 리셋하여 유효하지 않은 장 접근 에러 방지.
- **구절 다중 옵션 팝업**:
  - 본문 구절 클릭 시 `형광펜 / 메모 / 복사` 옵션이 있는 플로팅 팝업 제공.
  - **지능형 UI**: 이미 하이라이트된 구절 클릭 시 '하이라이트 취소' 버튼으로 동적 전환.
  - **인용 자동 추가**: 메모 작성 시 `[책 장:절]` 형식을 노트 본문에 자동 삽입.
- **맞춤형 묵상 양식 (Reflection Forms)**:
  - 노트 에디터 상단에 버튼 형식으로 제공 (예: '묵상 양식' 버튼 클릭 시 핵심 질문 가이드 삽입).
- **자정 세션 만료 정책 (Midnight Session Expiry)**:
  - 보안 및 일일 묵상 습관 형성을 위해 로그인 세션을 매일 자정(00:00:00)에 강제 만료.

### 2. 스마트 초기 말씀 로드 로직 (Smart Initial Selection)
- **로직**:
  - 기존 사용자: 가장 최신 읽기 기록의 다음 장을 메인 화면에 자동 로드.
  - 신규 사용자: 창세기 1장 기본 로드.
- **사이드바 개선**: '최근 읽은 말씀' 리스트를 시간 역순(최신순)으로 정렬하여 접근성 강화.

## 기술적 변경 사항
- **데이터베이스 경로 표준화**: `server/data/bible.db`를 단일 소스 오브 트루스(SSOT)로 확정 및 공식 문서화.
- **Node.js 네이티브 설정**: `.env` 파일 로드 방식을 Node.js 최신 규격(`process.loadEnvFile()`)으로 업그레이드.
- **인증 핸들링 보강**: 세션 만료 시 빈 화면 대신 로그인 페이지로 안전하게 리디렉션하는 에러 핸들링 로직 추가.
- **컴포넌트 통신**: `forwardRef` 및 `useImperativeHandle`을 사용하여 `BibleViewer`와 `NoteEditor` 간의 데이터 연동 구현.
