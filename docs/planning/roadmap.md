# 차기 작업 Roadmap
- 최신 배포 버전: v1.0
- 최신 배포일자: 2026년 1월 5일 //github release 기준
- 목표 버전: 미정
- 목표 개발일자: 미정

## 작업 흐름도

### 일반 흐름 (Minor/Major)
1. 희망 아이템 및 Bug 발견 사항을 **Inbox**에 자유롭게 추가합니다.
2. Inbox 아이템을 `[Major]`/`[Minor]`/`[Patch]` 라벨과 함께 **Categorized items**로 분류합니다.
3. 우선순위 선별을 통해 차기 버전에 포함할 작업을 결정하고, **목표 버전**을 설정합니다.
4. 버전 명세서를 작성합니다. (`spec-v버전명.md`)
   - 복수의 AI 에이전트 검토를 거쳐 확정
5. 명세서를 기반으로 개발을 진행합니다. (`logs/dev-log-v버전명.md`)
6. 개발 완료 후 검증 및 수정을 진행합니다. (`logs/verification-v버전명.md`)
7. Release Notes를 작성하고 배포합니다. (`logs/release-notes-v버전명.md`)
8. 배포 후, 완료된 작업을 **Completed** 섹션으로 이동합니다.
9. 차기 버전 흐름으로 이어갑니다.

### 긴급 흐름 (Patch/Hotfix)
치명적 버그 발생 시 단축 경로를 사용합니다.
1. Bug Revealed에 이슈 등록
2. 즉시 수정 및 테스트
3. Release Notes 작성 후 배포 (`logs/release-notes-v버전명.md`)
4. Completed 섹션으로 이동

## 📋 버전 관리 기준

### Major 버전 (2.0, 3.0, ...)
대규모 아키텍처 변경이나 핵심 사용자 경험이 근본적으로 바뀔 때 올립니다.
- **DB 스키마 대폭 변경**: 기존 데이터 마이그레이션이 복잡하거나 호환 불가
- **핵심 기능 재설계**: 읽기/노트/진도 중 하나의 워크플로우가 완전히 변경
- **다중 사용자 지원 도입**: 로그인/인증 시스템 추가 (단일→멀티 유저)
- **AI 기능 도입**: 외부 API 연동 및 새로운 상호작용 모드 추가

### Minor 버전 (1.1, 1.2, ...)
기존 구조 내에서 기능을 추가하거나 개선할 때 올립니다.
- **신규 기능 추가**: 백업/복구, 역본 대조, 통독 플랜 등
- **UI/UX 개선**: 반응형 최적화, 다크모드 보완, 접근성 강화
- **성능 향상**: 로딩 속도 개선, 캐싱 도입
- **버그 수정 묶음**: 여러 버그를 함께 수정하여 릴리즈

### Patch 버전 (1.1.1, 1.1.2, ...)
긴급 버그 수정이나 사소한 변경에 사용합니다.
- **핫픽스**: 치명적 버그 긴급 수정
- **오타/문구 수정**: 사용자에게 보이는 텍스트 교정
- **의존성 보안 패치**: 라이브러리 취약점 대응

## Categorized items

### 📖 읽기 (Reading)
- `[Minor]` **역본 대조 보기 (Parallel View)**: 한글/영어를 나란히 비교하며 읽기
- `[Minor]` **추가 역본 지원**: 개역개정, 새번역 ESV, NIV (라이선스 확보 후 추가)
- `[Minor]` **절(Verse) 단위 체크**: 장 전체가 아닌 절 단위 읽기 표시
- `[Minor]` **책을 넘나드는 범위 읽기**: 예) 창세기 50장 ~ 출애굽기 1장 연속 읽기
- `[Minor]` **다중 하이라이트**: 한 구절에 여러 색상/스타일 겹쳐서 표시
- `[Minor]` **고급 검색**: AND/OR 조건, 초성 검색, 검색 범위 지정
- `[Patch]` **읽기 완료 토글 개선**: 버튼 토글 로직 정교화 및 애니메이션 효과 추가
- `[Minor]` **구절 선택 시 다중 옵션**: 구절 탭/클릭 시 하이라이트, 노트에 추가, AI에게 질문 중 선택 가능

### 📝 노트 (Notes)
- `[Minor]` **마크다운 노트 지원**: 볼드, 이탤릭, 리스트 등 텍스트 서식 지원
- `[Minor]` **구절 인용 자동 추가**: 구절 선택 → 노트에 추가 시 `[책 장:절]` 형식으로 좌표 자동 삽입 후 노트 편집 가능

### 📊 진도 (Tracking)
- `[Minor]` **통계 기능 강화**: 월별 독서량 그래프, 성경 전체 진도율 시각화
- `[Minor]` **통독 플랜 (Reading Plans)**: 1년 1독, 맥체인 등 읽기표 템플릿 및 진도 체크

### ⚙️ 설정 (Settings & General)
- `[Minor]` **데이터 백업 및 복구** (JSON Export/Import) - *v1.0 미구현*
- `[Minor]` **오프라인 지원 (PWA)**: 인터넷 없이 동작 (Service Worker)
- `[Major]` **다중 사용자 지원**: 로그인/프로필 도입 (가족 공유)

### 🤖 AI 기능 (Advanced - 추후 개발)
- `[Major]` **AI 묵상 도우미**: 사용자 질문에 AI가 답변, 대화 내용을 노트에 정리
  - API Key 등록 필요 (ChatGPT, Gemini, Claude, Grok 등)
  - 구절 선택 → "AI에게 질문" 옵션으로 진입
  - 대화 종료 시 요약 정리 후 노트에 자동 추가 가능
  - 데스크톱/태블릿/모바일 UI 최적화 필요
