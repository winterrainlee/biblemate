
# UI/UX 설계 (요약)

### 전체 레이아웃
- **상단 헤더**: 앱 타이틀, 읽기표(Tracker) 버튼, 테마(🌙) 및 폰트(Aa) 설정
- **왼쪽 사이드바 (데스크톱 기준)**:
  - **달력**: 년/월 이동 및 읽은 날짜 표시
  - **성경 선택**: 책/장 범위, 역본(개역한글/OEB) 선택
  - **노트 미리보기**: 해당 날짜의 묵상 노트 요약
- **메인 영역 (오른쪽)**:
  - **성경 본문**: 절 리스트 (스크롤, 하이라이트 기능)
  - **묵상 노트 에디터**: 하단에 고정된 입력창 (날짜 표시, 텍스트 입력)
  - **액션 버튼**: [📋 복사] [💾 저장] [🗑️ 삭제]
- **모바일 흐름**: 헤더 → 달력 → 성경 선택 → 본문 → 하단 노트 에디터 순으로 수직 배치

### 필수 화면 상태
- `No Record`(읽기 기록 없음)
- `Loading`(본문 로딩)
- `Error`(본문/저장 실패) - 토스트 또는 모달로 표시
- `Saved`(저장 완료) - 토스트로 피드백
