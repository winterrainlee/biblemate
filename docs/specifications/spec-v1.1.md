# v1.1 명세서: 데이터 안전성 및 개인화

## 1. 개요 (Overview)
v1.1 버전은 **데이터 주권(백업/복구)**과 **사용자 경험 최적화(개인화)**에 초점을 맞춥니다. 모바일 사용성과 묵상 집중 모드를 강화합니다.

## 2. 주요 기능 (Features)

### 2.1. 데이터 백업 및 복구 (Data Backup & Restore)
- **목표**: 사용자가 자신의 데이터를 로컬 파일로 저장하고 복구할 수 있게 하여, 데이터 유실 위험을 줄입니다.
- **사용자 스토리**: "나는 내 노트와 형광펜 표시를 파일로 다운로드해서 백업해두거나 다른 컴퓨터로 옮기고 싶습니다."
- **구현 전략**:
    - **백엔드**:
        - `GET /api/backup/export`: `reading_progress`, `notes`, `highlights` 테이블을 조회하여 표준화된 JSON 포맷으로 반환합니다.
        - `POST /api/backup/import`: JSON 파일을 받아 스키마를 검증하고, 기존 데이터를 **덮어쓰기(Overwrite)**합니다. (v1.1에서는 충돌 방지를 위해 단순 덮어쓰기 정책 사용, 경고 문구 필수)
    - **프론트엔드 (`Settings.jsx`)**:
        - "데이터 내보내기" 버튼 -> `biblemate_backup_YYYYMMDD.json` 파일 다운로드.
        - **다운로드 완료 알림**: PC/모바일 다운로드 완료 시, "파일이 저장되었습니다. 분실 방지를 위해 이메일이나 클라우드에 보관하는 것을 권장합니다." 메시지 표시 (Toast/Alert).
        - "데이터 가져오기" 파일 입력 -> JSON 파일 읽기 -> 서버 전송 -> 성공 시 페이지 새로고침.
        - "데이터 가져오기" 파일 입력 -> JSON 파일 읽기 -> 서버 전송 -> 성공 시 페이지 새로고침.

### 2.2. 사이드바 컴팩트 모드 (Sidebar Compact Mode)
- **목표**: 사이드바의 수직 공간을 절약하여, 특히 모바일 환경에서 더 많은 네비게이션 항목이 보이도록 합니다.
- **사용자 스토리**: "모바일에서 볼 때 성경 선택 박스가 공간을 너무 많이 차지해서 아래 메뉴가 잘 안 보입니다. 한 줄로 줄여주세요."
- **구현 전략**:
    - **대상**: `client/src/components/Sidebar.jsx`
    - **변경**: "성경 역본 선택"과 "책/장 선택" 드롭다운의 배치를 세로(Column)에서 가로(Row)로 변경합니다.
    - **반응형**: 화면이 너무 좁을 때는 자연스럽게 줄바꿈되거나, 비율을 조정하여 깨지지 않도록 합니다.

### 2.3. 대시보드 블록 토글 (Dashboard Block Toggles)
- **목표**: 사용자가 '읽기' 또는 '묵상' 중 하나에만 온전히 집중할 수 있는 환경을 제공합니다.
- **사용자 스토리**: "주일에는 설교 노트만 쓰고 싶어서 성경 본문은 끄고 싶어요." / "성경만 쭉 읽고 싶은데 노트 칸이 거슬려요."
- **구현 전략**:
    - **상태 관리**: `localStorage`에 `dashboardConfig` 저장 (예: `{ showReading: true, showNotes: false }`).
    - **프론트엔드 (`Settings.jsx`)**: "화면 표시 설정" 섹션 추가 및 ON/OFF 토글 스위치 배치.
    - **프론트엔드 (`ReadingDashboard.jsx`)**:
        - 그리드 레이아웃 동적 조정.
        - `showReading` OFF 시: 노트 영역을 화면 전체 너비/높이로 확장.
        - `showNotes` OFF 시: 성경 영역을 화면 전체 너비/높이로 확장.
        - 둘 다 OFF 되는 상황 방지 (최소 하나는 켜져 있어야 함).
