# PR: v1.3.0 백업 안정성 강화 및 UX 개선

## 📌 개요
이 PR은 백업 기능의 신뢰성을 높이기 위한 안정성 강화 작업과 묵상 집중 모드의 레이아웃 개선을 포함합니다.
기존 백업 시스템의 취약점(대용량 파일, 잘못된 포맷, id 누락)을 보완하고, 사용자 피드백을 모달 팝업으로 개선하였습니다.

## 변경된 기능
### 1. 백업/복구 (Backup/Restore)
- **Import 안정화**: 
  - `id` 필드 누락 시 자동 생성 처리 (`server/routes/backup.js`)
  - 5MB 용량 제한 및 데이터 무결성(필수 필드/타입) 검사 로직 추가
- **UX 개선**:
  - Import/Export 성공 및 실패 시 **모달 팝업**을 통해 명확한 결과 제공 (`Settings.jsx` + `Modal.jsx`)
  - 다운로드 로직 중복 실행 버그 수정

### 2. 레이아웃 (Layout)
- **Full Height Note Editor**: 대시보드에서 '말씀 영역'을 끄면 노트 에디터가 자동으로 전체 높이로 확장되도록 CSS/Logic 수정
