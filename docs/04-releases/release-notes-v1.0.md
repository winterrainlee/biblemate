## ✨ 새로운 기능 (Features)

### 📖 말씀 읽기 (Reading)
- **이중 역본 지원**: 개역한글(KRV) 및 영어(BBE) 지원 — **모두 저작권 자유 역본**
- **역본 즉시 전환**: 읽는 도중 전환해도 현재 구절 위치 유지
- **읽기 상태 표시**: 본문 상단에 현재 위치(장/절)와 '읽음' 배지 표시
- **이전 읽은 날짜**: 본문에서 해당 구절을 언제 읽었는지 날짜 배지 표시

### 📝 묵상 기록 (Writing)
- **날짜별 묵상**: 매일의 묵상을 기록하고, 자동 저장 지원
- **스마트 복사**: `[날짜] 읽은 범위 + 내용` 포맷으로 클립보드 복사
- **안전한 저장**: 덮어쓰기 방지 로직 및 삭제 기능

### 📊 진도 관리 (Tracking)
- **통합 대시보드**: 달력, 성경 선택, 노트 작성을 한 화면에서 처리
- **다회 읽기 지원**: 하루에 여러 본문을 읽어도 모두 기록
- **월별 히스토리**: 달력을 통해 월별 읽기 현황 파악
- **읽기표 모달**: 전체 성경 66권의 장별 진도율 시각화

### ⚙️ 사용자 경험 (Customization)
- **다크 모드**: 시스템 설정 또는 사용자 선호에 따라 완벽 지원
- **접근성 강화**: 글자 크기 10px~24px 미세 조절
- **반응형 디자인**: 데스크톱, 태블릿, 모바일 최적화

### 🛠️ 개발자 경험 (DX)
- **간편 실행**: `start-biblemate.bat`로 원클릭 서버 실행
- **간편 설치**: `setup.bat`로 의존성 설치 및 DB 자동 생성
- **접속 안내**: 실행 시 로컬 IP 주소 자동 표시 (모바일 접속 용이)

## 📦 설치 방법

### 요구사항
- Node.js 18 이상
- Windows 10/11 (배치 파일 기준)

### 설치 절차
```bash
# 1. 레포지토리 복제
git clone https://github.com/winterrainlee/biblemate.git
cd biblemate

# 2. 초기 설정 (Windows)
setup.bat

# 3. 서버 실행 (Windows)
start-biblemate.bat
```

### 접속
- **PC**: http://localhost:5173
- **모바일**: 실행 창에 표시되는 IP 주소 사용 (예: http://192.168.0.X:5173)
