# Release Notes v1.3.0

> **Date: 2026-01-08**

## 🚀 주요 변경 사항 (Highlights)
### 1. 백업 시스템 안정성 강화 (Backup Stability)
- **백업 파일 포맷 개선**: 버전 관리 및 스키마 검증을 위한 메타데이터(`app_version`, `schema_version`) 추가
- **가져오기(Import) 안전장치 추가**:
  - **용량 제한**: 5MB 이상의 대용량 파일 업로드 차단
  - **무결성 검사**: 필수 데이터(날짜, 성경 구절 등) 누락 및 타입 오류 검증 로직 도입
  - **버그 수정**: 데이터 가져오기 시 `id` 필드가 없을 경우 DB 오류(500)가 발생하는 문제 해결
- **사용자 피드백 개선**: 기존의 일시적인 토스트 메시지 대신, 성공/실패 결과를 명확히 보여주는 **모달 팝업(Modal)** 도입

### 2. 레이아웃 및 UX 개선
- **묵상 집중 모드 최적화**: 말씀 패널을 껐을 때 노트 에디터가 화면 전체 높이를 차지하도록 개선하여 몰입감 향상

## 🐛 버그 수정 (Bug Fixes)
- 백업 파일 내보내기(Export) 시 다운로드 로직이 중복 실행되어 콘솔 에러가 발생하던 문제 수정
- 잘못된 문법(이스케이프되지 않은 따옴표)이 포함된 JSON 파일 로딩 시 앱이 멈추는 현상 방지

## 🔧 기술적 변경 사항 (Technical)
- Server: `express.json({ limit: '5mb' })` 설정 추가
- Client: `Settings.jsx` 내 DOM 조작 로직 제거 및 React State 기반 Modal 제어로 리팩토링
- Database: `reading_logs` 테이블 Insert 시 `id` 자동 생성(`null` 처리) 지원

## 📝 업데이트 가이드
이번 업데이트는 백업 파일 포맷 변경을 포함하므로, 기존 v1.1/v1.2에서 생성된 백업 파일도 호환되도록 처리되었습니다. 단, v1.3에서 생성한 백업 파일은 구버전 앱에서 호환되지 않을 수 있습니다.
