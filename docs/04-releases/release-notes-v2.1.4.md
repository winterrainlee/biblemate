# Release Notes v2.1.4

**배포일**: 2026년 4월 30일  
**버전**: v2.1.4

## 핵심 변경
- 묵상일지와 성경읽기 모드의 구절별 묵상 카드에 개별 복사 아이콘을 추가했습니다.
- 복사 아이콘은 수정/삭제 아이콘 앞에 배치되며, 클릭 시 해당 묵상 내용만 클립보드에 저장됩니다.
- 복사 성공 시 해당 카드만 체크 아이콘으로 잠시 전환되어 동작 결과를 확인할 수 있습니다.
- 성경읽기 모드 좌/우 묵상 사이드바와 모바일 묵상 보기 팝업에서도 같은 복사 UX를 제공합니다.

## 기술 메모
- 기존 전체 묵상 복사의 클립보드 fallback 로직을 묵상일지 개별 복사에 재사용하고, 성경읽기 모드에도 동일 fallback을 적용했습니다.
- 백엔드 API, DB 스키마, 저장 데이터 포맷 변경은 없습니다.

## 검증
- `client` 빌드가 통과했습니다.
