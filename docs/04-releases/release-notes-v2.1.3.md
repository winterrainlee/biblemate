# Release Notes v2.1.3

**배포일**: 2026년 3월 9일  
**버전**: v2.1.3

## 핵심 변경
- 에스겔 교정 스크립트(`server/scripts/fix_ezekiel.js`)를 `HAN` 기준으로 전면 보강했습니다.
- 절 파싱 안정화(절 marker 기반, 마지막 절 경계 절단) 및 무결성 검증(연속 절/빈 본문/오염 패턴)을 추가했습니다.
- 장별 트랜잭션과 `--dry-run` 옵션으로 데이터 반영 안전성을 강화했습니다.
- `bible-corrections.json`의 욥기 42장 보정 누락 필드를 정리해 전체 성경 재임포트가 정상 동작하도록 수정했습니다.

## 데이터 교정 결과
- KRV/BBE 66권 전체 재임포트를 다시 실행했고, 보정 547건이 모두 적용되었습니다.
- 에스겔 1~48장을 `HAN` 기준으로 다시 반영했습니다.
- 사용자 확인 이슈가 있던 **에스겔 27장(KRV)** 의 병합 오염이 제거되었고, `27:33~36` 구절이 정상화되었습니다.
- 최종 검증 기준 집계:
  - KRV 66권 / 30,989절
  - BBE 66권 / 31,104절

## 검증 메모
- 로컬 재현 기준 `node --check server/scripts/fix_ezekiel.js`, 전체 dry-run, 전체 재임포트, 에스겔 1~48장 apply가 모두 통과했습니다.
- 샘플 대조: `겔 16:34`, `겔 16:63`, `겔 27:1`, `겔 27:33~36`, `겔 48:35`, `창 1:1`, `시 23:1`, `마 1:1`, `계 22:21`
