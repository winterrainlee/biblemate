# Release Notes v2.1.2

**배포일**: 2026년 3월 9일
**버전**: v2.1.2

이번 배포는 에스겔서 서버 데이터의 무결성을 개선하기 위한 핫픽스입니다. 

## 🛠️ Data Integrity & Hotfixes
- 외부 소스의 데이터 포맷 오류로 인해 잘못 표시되던 **에스겔서 1~48장의 본문(KRV)** 전체를 다시 추출하여 올바르게 DB를 업데이트했습니다.
- 영어 버전(BBE, WEB) 및 다른 역본은 기존 내용을 유지하도록 선별적 업데이트를 적용했습니다.
- 사용자의 개인 데이터(묵상 노트, 표시, 형광펜)에는 영향을 주지 않고 안전하게 본문만 교체되었습니다.

## 📝 내부 개선 (Documentation)
- Fly.io 환경과 같이 지속성 볼륨을 사용하는 서버 구조에서 **운영 DB 핫픽스를 적용하는 방법**(`lessons.md`)을 추가 기록했습니다.
- [Dev Log v2.1](03-logs/dev-log-v2.1.md) 및 [Roadmap](../01-planning/roadmap.md)을 최신화했습니다.
