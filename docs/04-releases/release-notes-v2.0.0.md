# Release Notes - v2.0.0 (2026-01-26)

## 📖 말씀에 깊이를 더하는 BibleMate v2.0

이번 v2.0 업데이트는 단순한 기능 추가를 넘어, 말씀을 읽고 묵상하는 '경험' 자체를 재설계했습니다. 이제 더욱 쾌적하고 깊이 있는 환경에서 말씀을 가까이 하세요.

### 1. 직관적인 모드 전환 (Reading vs Journal)
- **성경 읽기 모드**: 오직 말씀에만 집중할 수 있는 깔끔한 뷰를 제공합니다.
- **묵상일지 모드**: 내가 남긴 묵상과 기도, 읽기 기록을 일기처럼 모아볼 수 있는 전용 공간입니다.

### 2. 구절별 묵상과 실시간 피드백
- **더 세밀해진 묵상**: 한 장 단위가 아니라, 이제 원하는 **구절을 콕 집어서** 묵상을 남길 수 있습니다. 구절과 별개로 묵상을 남기고 싶을 경우, 묵상일지의 자유 묵상을 활용할 수 있습니다.
- **본문 표시 (📝)**: 본문을 읽을 때 내가 묵상을 남긴 구절에 표시가 나타나, 과거의 은혜를 실시간으로 다시 확인할 수 있습니다.
- **다중 구절 선택**: 드래그 한 번으로 여러 구절을 선택해 형광펜을 칠하거나 묵상을 남길 수 있습니다.

### 3. 나만의 성경 연구소 (3-Column Layout)
- 데스크톱의 넓은 화면을 100% 활용하여 성경 본문 옆에 관련 묵상들이 실시간으로 함께 표시됩니다.

### 4. 눈이 편안한 디자인과 개인화
- **프리미엄 다크 모드**: 시력 보호를 위해 튜닝된 새로운 블루 테마가 적용되었습니다.
- **서체 설정**: 가독성이 좋은 '명조'와 깔끔한 '고딕' 중 선택할 수 있습니다.
- **서버 설정 동기화**: 한 곳에서 설정한 글자 크기와 형광펜 이름이 모든 기기에 똑같이 적용됩니다.

### 5. 다중 역본 지원
- **현대적인 영어 (WEB)**와 **쉬운 영어 (BBE)**가 추가되었습니다. 한글과 영어를 오가며 더 깊은 의미를 발견해 보세요.

### 6. 모바일 및 안정성 개선
- **적응형 네비게이션**: 폰에서도 책과 장을 선택하기 훨씬 편해졌습니다.
- **안전한 기록**: '오늘 읽음' 전용 버튼과 강화된 백업/복구 시스템으로 소중한 데이터를 보호합니다.
