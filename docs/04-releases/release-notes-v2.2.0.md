# Release Notes v2.2.0

**배포일**: 2026-06-12
**버전**: v2.2.0

## 핵심 변경

- 모바일 성경 읽기 화면을 말씀 중심으로 재구성했습니다.
- 구절 선택 후 `묵상하기`가 가장 먼저 보이도록 액션 흐름을 바꿨습니다.
- 모바일 묵상 작성은 전체 화면 오버레이로 열리며, 선택한 말씀 본문을 상단에 항상 표시합니다.
- 현재 장의 묵상 목록을 모바일 바텀시트에서 확인할 수 있습니다.
- 하단 action bar로 이전 장, 읽음 표시, 다음 장, 묵상일지 이동을 한 손으로 수행할 수 있습니다.
- 묵상일지에서 날짜 선택 시트, 오늘 복귀, 최근 기록 목록, 모바일 월간 요약을 제공합니다.
- 읽기표에서 `다음 안 읽은 장 읽기` 또는 책 row 탭으로 바로 성경 읽기를 시작할 수 있습니다.
- 성경 본문 전용 `Aa` 글자 크기 조절을 추가했습니다.

## 안정성 및 접근성

- iOS Safari/PWA를 고려해 `viewport-fit=cover`, safe-area CSS 변수, `100dvh/100svh` fallback을 적용했습니다.
- 입력/팝업/시트 조작 중 장·날짜 스와이프가 오작동하지 않도록 guard를 보강했습니다.
- 주요 모바일 버튼의 `aria-label`과 44px 터치 영역을 보강했습니다.
- legacy `/api/notes` 호출을 `/api/free-notes`로 정리했습니다.

## 검증

- `cd client && npm run lint` 성공, warning 없음
- `cd client && npm run build` 성공
- iPhone Safari 실기기 수동 QA 통과
- 로컬 Vite/API proxy 응답 확인

## 기술 메모

- 데스크탑 3컬럼 성경 읽기 경험은 유지하고, 모바일에서만 compact bar, 바텀시트, 전체 화면 작성 오버레이, 하단 action bar를 적용했습니다.
- 읽기표에서 성경 화면으로 이동할 때는 `localStorage`의 pending Bible location을 사용합니다.
- 오프라인/PWA 서비스 워커, `묵상 대상일`과 `작성일` 분리, 전역 하단 탭바는 후속 버전 결정 항목으로 남겼습니다.
