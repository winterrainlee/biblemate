# Release Notes v2.3.3

**배포일**: 2026-07-07  
**버전**: v2.3.3  
**상태**: 배포 완료

## 핵심 변경

- 구절별 묵상을 저장하면 해당 날짜의 해당 장이 자동으로 읽음 처리됩니다.
- 이미 읽음 기록이 있는 장은 중복 저장하지 않습니다.
- 성경 읽기 화면에서 묵상 저장 후 읽음 완료 상태가 바로 갱신됩니다.
- 앱 표시 버전과 package version을 v2.3.3으로 갱신했습니다.

## 검증

- `cd client && npm run lint`
- `cd client && npm run build`
- `git diff --check`
- 임시 DB 서버에서 `POST /api/verse-notes` 후 읽기 로그 자동 생성 확인
- 같은 구절 묵상을 다시 저장해 읽기 로그가 중복 생성되지 않음 확인

## 남은 확인

- 배포 후 실제 계정 데이터에서 묵상 저장 → 읽음 상태 반영 흐름을 확인합니다.
