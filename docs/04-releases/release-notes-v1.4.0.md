# BibleMate v1.4.0 Release Notes

**배포일**: 2026-01-12
**유형**: Feature Release (UX Improvements & Security)

## ✨ 새로운 기능 (New Features)

### 1. 성경 읽기표 페이지 (Bible Reading Chart) - [R2]
- 기존 팝업 형태에서 **전용 페이지(/chart)**로 업그레이드되었습니다.
- **필터 기능**: 전체 / 구약 / 신약 버튼을 통해 보고 싶은 영역만 골라볼 수 있습니다.
- **반응형 디자인**: 모바일에서도 한 눈에 진행 상황을 파악하기 쉽게 개선되었습니다.
- **상세 통계**: 전체 및 구약/신약별 읽기 진행률(%)과 장 수를 정확하게 보여줍니다.

### 2. 읽기 화면 분할 리사이저 (Split Screen Resizer) - [R4]
- 데스크탑 환경에서 **말씀 영역**과 **묵상 영역**의 너비를 자유롭게 조절할 수 있습니다.
- 중앙의 회색 바를 드래그하여 원하는 비율을 맞춰보세요.
- 설정한 비율은 저장되어 다음에 접속해도 그대로 유지됩니다.

### 3. 읽기 완료 버튼 스타일 개선 - [R1]
- 딱딱했던 버튼이 **부드러운 알약(Pill) 모양**으로 예뻐졌습니다.
- 완료 시 초록색 체크 아이콘과 함께 기분 좋은 애니메이션 효과를 제공합니다.
- 토스트(Toast) 메시지를 통해 저장 여부와 응원 문구를 확실하게 보여줍니다.

## 🔒 보안 강화 (Security)

### 1. CORS 보안 정책 적용 - [N1]
- 서버 보안을 위해 `ALLOWED_ORIGINS` 환경 변수를 통한 접근 제어 기능이 추가되었습니다.
- 이제 허용된 도메인(내 사이트) 외의 불법적인 접근을 원천 차단할 수 있습니다.

## 🐛 버그 수정 및 개선 (Fixes & Improvements)

- **[Mobile] 묵상 집중 모드 개선**: 모바일에서 '묵상 영역'만 켰을 때(집중 모드), 에디터 높이가 화면의 75%까지 시원하게 늘어나도록 개선했습니다. (기존엔 작게 고정됨)
- **[UI] 사이드바 문구 수정**: '오늘의 말씀' -> '오늘 읽은 말씀'으로 더 명확하게 변경했습니다.
