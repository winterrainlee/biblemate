# Release Notes v2.3.2

**배포일**: 2026-06-28  
**버전**: v2.3.2  
**상태**: 배포 완료

## 핵심 변경

- 모바일 성경 읽기 화면의 헤더를 압축해 구절 선택 시 사용할 수 있는 공간을 늘렸습니다.
- 구절 선택 중 모바일 헤더와 하단 액션 바가 선택 팝업을 가리지 않도록 숨김 처리를 추가했습니다.
- 로그인 화면 말씀 문구를 두 줄로 나누고 `(시편 119:105)` 출처를 표시했습니다.
- 앱 표시 버전과 package version을 v2.3.2로 갱신했습니다.
- `.claude/` 로컬 작업 폴더를 Git 추적 대상에서 제외했습니다.

## 검증

- `cd client && npm run lint`
- `cd client && npm run build`
- `git diff --check`
- `git status --short --ignored`

## 남은 확인

- 실제 모바일 기기에서 구절 선택 팝업의 체감 높이와 하단 safe-area 동작을 확인합니다.
