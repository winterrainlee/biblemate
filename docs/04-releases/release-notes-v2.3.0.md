# Release Notes v2.3.0

**배포일**: 2026-06-13
**버전**: v2.3.0
**상태**: 배포 완료

## 핵심 변경

- BibleMate의 시각 언어를 "나만의 서재에서 읽는 성경" 컨셉으로 재구성했습니다.
- 라이트 모드는 따뜻한 크림 종이와 세피아 잉크 계열로, 다크 모드는 밤의 서재와 촛불 금색 계열로 조정했습니다.
- 성경 본문 기본 글꼴을 `Noto Serif KR`로 바꾸고, `명조 / 고운바탕 / 고딕` 본문 글꼴 선택 옵션을 제공합니다.
- 성경 본문 영역을 주변보다 한 단계 밝은 paper surface로 정리했습니다.
- 묵상 카드와 묵상일지를 메모지/기도 노트에 가까운 문법으로 조정했습니다.
- 기능 중심 문구를 묵상 흐름에 맞는 존댓말 마이크로카피로 정리했습니다.
- 파비콘과 홈 화면 아이콘을 새 서재 컨셉에 맞게 리디자인했습니다.

## 안정성 및 회귀 기준

- DB/API 계약 변경 없음
- v2.2 모바일 UX 구조 유지
- 데스크톱 3컬럼 성경 읽기 경험 유지
- WCAG AA 대비 기준 확인 예정
