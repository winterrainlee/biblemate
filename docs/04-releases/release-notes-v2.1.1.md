# Release Notes - v2.1.1 (Hotfix)

## 🚀 개요
에스겔 16장에서 발견된 심각한 본문 오류(구절 밀림 및 오염)를 수정했습니다.

## 🛠️ 수정 사항
- **에스겔 16장 본문 정상화**:
    - 34절의 내용 중복 문제로 발생했던 구절 밀림(35~62절)을 해결했습니다.
    - 63절의 본문 오염 및 불필요한 기술 태그를 제거했습니다.
    - 대한성서공회 정본과 대조하여 본문 텍스트를 최신화했습니다.

## 📦 변경 파일
- `server/data/bible-corrections.json`: 교정 데이터 추가 (v1.3.2)
- `server/data/bible.db`: 교정 데이터 반영 완료

## 확인 방법
- 성경 읽기 화면에서 에스겔 16장을 열어 34절 이후의 내용이 문맥에 맞게 표시되는지 확인하십시오.
- 63절 하단에 `[Ezekiel 16:64]`와 같은 이상한 메시지가 없는지 확인하십시오.
