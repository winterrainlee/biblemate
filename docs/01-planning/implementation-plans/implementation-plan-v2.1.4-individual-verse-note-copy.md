# Implementation Plan v2.1.4 - 개별 구절 묵상 복사

## 목표
- 묵상일지와 성경읽기 모드의 구절별 묵상 카드에서 수정/삭제 아이콘 앞에 복사 아이콘을 추가한다.
- 개별 복사 시 클립보드에는 해당 묵상 내용만 저장한다.

## 구현 범위
- `JournalPage.jsx`
  - 전체 묵상 복사와 개별 묵상 복사가 함께 사용할 클립보드 헬퍼를 추가한다.
  - 개별 구절 묵상 복사 핸들러를 추가한다.
  - 카드 액션 순서를 `복사 → 수정 → 삭제`로 배치한다.
  - 복사 성공 시 해당 카드만 `Check` 아이콘으로 2초간 전환한다.
- `JournalPage.css`
  - 개별 복사 성공 상태와 카드 액션 정렬 스타일을 추가한다.
- `BibleViewer.jsx`
  - 성경읽기 모드 좌/우 묵상 사이드바와 모바일 묵상 보기 팝업에 동일한 개별 복사 액션을 추가한다.
  - 카드 액션 렌더링을 공통 함수로 정리해 `복사 → 수정 → 삭제` 순서를 일관되게 유지한다.

## 제외 범위
- 백엔드 API, DB 스키마, 저장 데이터 포맷은 변경하지 않는다.
- 개별 복사 텍스트에 구절명, 날짜, 섹션 제목은 포함하지 않는다.

## 검증 계획
- `client` 빌드가 성공해야 한다.
- 묵상일지와 성경읽기 모드 구절별 묵상 카드에서 복사 아이콘이 수정 아이콘 앞에 보여야 한다.
- 복사 클릭 시 해당 묵상 `content`만 클립보드에 저장되어야 한다.
- 여러 카드 중 클릭한 카드만 성공 상태로 바뀌고 2초 뒤 원복되어야 한다.
- 수정 모드에서는 기존처럼 액션 아이콘 영역이 숨겨져야 한다.
