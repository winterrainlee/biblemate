# implementation-plan-v1.4.1-codex-agent-rules.md

## 목표
- Codex CLI 실행 흐름에 맞게 `AGENTS.md`를 전면 재구성한다.
- 승인 게이트, 워크플로우, 문서/브랜치/배포 규칙을 체크리스트 중심으로 정리한다.

## 변경 범위
- `AGENTS.md` 전면 재작성
- `docs/01-planning/implementation-plans/implementation-plan-v1.4.1-codex-agent-rules.md` 신규 작성 (본 문서)

## 기대 결과
- 핵심 규칙이 한눈에 보이는 체크리스트로 정렬된다.
- 승인 게이트/워크플로우/문서/브랜치/배포/Windows/교훈이 누락 없이 포함된다.
- Codex CLI 환경(샌드박스/승인/도구 사용)이 프로젝트 규칙과 충돌 없이 정렬된다.

## 변경 단계
1. 기존 규칙을 목적별로 재분류하고 중복을 제거한다.
2. 체크리스트와 핵심 섹션 중심으로 문서를 재구성한다.
3. Codex CLI 환경 규칙을 추가하고 용어를 통일한다.
4. 누락 여부를 최종 점검한다.

## 검증 절차
- `AGENTS.md`에 다음 항목 포함 여부를 수동 점검한다:
  - 언어 규칙
  - 승인 게이트
  - 6단계 워크플로우
  - 문서 구조/필수 문서
  - 버전/브랜치 전략
  - 배포 절차
  - Windows 환경 참고
  - 핵심 교훈
  - 프로젝트 구조/기술 스택
- Markdown 렌더링 시 구조가 명확한지 확인한다.
