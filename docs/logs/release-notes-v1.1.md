# BibleMate v1.1.0 Release Notes

**릴리즈 날짜**: 2026-01-06  
**버전**: v1.1.0  
**테마**: 클라우드 확장 및 보안 강화

---

## 🎯 주요 변경사항

v1.1.0은 BibleMate가 개인 PC를 넘어 **전 세계 어디서나 안전하게** 사용할 수 있는 서비스로 도약한 기념비적인 업데이트입니다.

### ✨ 새로운 기능

#### 1. ☁️ Fly.io 클라우드 배포 지원
- 이제 24시간 상시 가동되는 클라우드 서버에 BibleMate를 배포할 수 있습니다.
- SQLite 공식 볼륨 마운트를 통해 서버 재시작 시에도 데이터가 안전하게 보존됩니다.

#### 2. 🔒 액세스 암호 보호 (Access Password)
- 외부 서버 배포 시, 나만이 내 기록을 볼 수 있도록 암호를 설정할 수 있습니다.
- 환경변수 `ACCESS_PASSWORD`를 통해 보안 기능을 즉시 활성화하세요.
- 보안 등급을 유지하면서도 자동 로그인을 지원하여 편리한 사용성을 유지했습니다.

#### 3. 📦 데이터 주권 확보 (백업 및 복구)
- 내 노트, 하이라이트, 읽기 기록을 한 번에 JSON 파일로 백업할 수 있습니다.
- 기기 변경이나 데이터 유실 걱정 없이 안심하고 기록하세요.

#### 4. 📱 모바일 UX 최적화
- 사이드바의 성경 선택 UI를 컴팩트하게 개선하여 모바일 화면 공간을 획기적으로 확보했습니다.
- 읽기/묵상 집중 모드(토글)를 통해 나에게 맞는 최적의 대시보드를 구성할 수 있습니다.

---

## 🔧 기술적 개선

- **Docker 빌드 최적화**: 3단계 멀티스테이지 빌드를 통해 빌드 시점에 성경 DB를 자동 생성하도록 개선.
- **보안 미들웨어 도입**: `cookie-parser` 및 세션 기반 인증 필터 적용.
- **성능 개선**: 대시보드 리액트 컴포넌트 최적화 및 동적 그리드 레이아웃 적용.

---

## 📝 시작하기 (클라우드 사용자)

배포된 서버 주소로 접속한 뒤, 설정하신 `ACCESS_PASSWORD`를 입력하여 로그인하세요. 처음 사용하신다면 [Fly.io 배포 가이드](../deploy-flyio.md)를 참고하여 직접 나만의 서버를 구축하실 수 있습니다.
