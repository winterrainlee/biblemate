# BibleMate v1.1.0 Release Notes

**릴리즈 날짜**: 2026-01-06  
**버전**: v1.1.0  

---

## 🎯 주요 변경사항

v1.1.0 버전에서는 데이터 관리 기능 강화와 클라우드 배포 환경 구축을 진행했습니다.

### ✨ 추가된 기능

#### 1. Fly.io 클라우드 배포
- Fly.io를 통해 어디서나 접속할 수 있는 환경을 구축했습니다.
- SQLite 볼륨 설정을 통해 데이터가 초기화되지 않도록 처리했습니다.

#### 2. 액세스 암호 보호
- 외부 접속 시 보안을 위해 `ACCESS_PASSWORD` 환경변수 기반의 암호 확인 절차를 추가했습니다.
- 쿠키 기반의 세션 관리와 로그인/로그아웃 기능을 포함합니다.

#### 3. 데이터 백업 및 복구
- 작성한 노트, 하이라이트, 읽기 기록을 JSON 파일로 저장하거나 다시 불러올 수 있습니다.
- 환경 변경 시 데이터를 옮기거나 백업하는 용도로 사용할 수 있습니다.

#### 4. UI/UX 개선
- 사이드바 성경 선택 UI를 가로 배치로 변경하여 모바일에서의 가독성을 높였습니다.
- 설정 페이지에서 말씀 영역과 묵상 영역을 각각 켜고 끌 수 있는 기능을 추가했습니다.

---

## 🔧 기술적 수정 사항

- Docker 3단계 멀티스테이지 빌드 적용 (자동 DB 생성 포함)
- 서버 인증 미들웨어 및 `cookie-parser` 적용
- 대시보드 그리드 레이아웃 최적화

## 📝 참고 사항

- 클라우드 서버 이용 시 환경변수로 암호를 설정해야 보안 기능이 활성화됩니다.
- 자세한 배포 방법은 [Fly.io 배포 가이드](../deploy-flyio.md)를 참고하세요.
