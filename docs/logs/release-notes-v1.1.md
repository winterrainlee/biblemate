# BibleMate v1.1 Release Notes

**릴리즈 날짜**: 2026-01-05  
**버전**: v1.1  
**테마**: 데이터 안전성 및 개인화

---

## 🎯 주요 변경사항

v1.1은 **데이터 주권**과 **사용자 경험 최적화**에 초점을 맞춘 업데이트입니다.

### ✨ 새로운 기능

#### 1. 📦 데이터 백업 및 복구
- **데이터 내보내기**: 노트, 하이라이트, 읽기 기록을 JSON 파일로 저장
  - 파일명: `biblemate_backup_YYYYMMDD.json`
  - 다운로드 완료 시 보관 권장 안내 메시지 표시
- **데이터 가져오기**: 백업 파일을 선택하여 데이터 복원
  - 복구 전 경고 메시지: "복구 전 현재 데이터를 백업하는 것을 권장합니다"
  - 기존 데이터 덮어쓰기 정책 (전체 교체)
- **사용 방법**: Settings → "데이터 백업 및 복구" 섹션

#### 2. 📱 사이드바 컴팩트 모드
- 성경 선택 UI를 세로에서 가로 레이아웃으로 변경
- 책 선택과 장 선택을 한 줄에 배치 (90%/110% 비율)
- 모바일 환경에서 수직 공간 절약
- 반응형 디자인: 좁은 화면에서는 자연스럽게 줄바꿈

#### 3. 👁️ 대시보드 블록 토글
- 말씀 영역과 묵상 영역을 개별적으로 표시/숨김 가능
- **사용 시나리오**:
  - 성경 읽기에만 집중: 묵상 영역 OFF
  - 묵상 작성에만 집중: 말씀 영역 OFF
- 설정이 localStorage에 저장되어 새로고침 후에도 유지
- 최소 하나의 영역은 항상 켜져 있도록 보호
- **사용 방법**: Settings → "화면 표시 설정" 섹션

## 🔧 기술적 개선

### 백엔드
- 새로운 API 엔드포인트 추가:
  - `GET /api/backup/export`: 전체 데이터 내보내기
  - `POST /api/backup/import`: 데이터 가져오기 (트랜잭션 처리)
- 데이터 무결성 보장: SQLITE 트랜잭션 활용

### 프론트엔드
- Settings 페이지 대폭 확장
- localStorage 기반 사용자 설정 관리
- 조건부 렌더링을 통한 동적 UI 제어
- 반응형 레이아웃 개선

## 📝 사용자 가이드

### 데이터 백업하기
1. 설정 페이지로 이동
2. "데이터 백업 및 복구" 섹션에서 "데이터 내보내기" 클릭
3. JSON 파일이 다운로드됨
4. 파일을 안전한 곳에 보관 (이메일, 클라우드 등)

### 데이터 복구하기
1. 설정 페이지로 이동
2. "데이터 가져오기" 클릭
3. 백업 파일 선택
4. 경고 메시지 확인 후 진행
5. 자동으로 페이지가 새로고침되며 데이터 복원 완료

### 화면 표시 설정
1. 설정 페이지로 이동
2. "화면 표시 설정" 섹션에서 원하는 영역 토글
3. 홈 화면에서 변경사항 즉시 반영

## 💡 팁

- **기기별 설정**: localStorage는 브라우저별로 독립적이므로, 데스크톱과 모바일에서 서로 다른 화면 설정을 유지할 수 있습니다.
- **정기적인 백업**: 중요한 묵상 노트는 정기적으로 백업하여 데이터 유실을 방지하세요.
- **컴팩트 모드**: 모바일에서 사이드바가 더 깔끔하게 보입니다!
