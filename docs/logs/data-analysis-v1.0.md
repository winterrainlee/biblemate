## 📈 장기 사용 시 데이터 증가 예측
> 시나리오: 매일 성경 읽기(1-3장) + 묵상 1편(500자) + 하이라이트 5개

### 기간별 예상 데이터량
| 기간 | 읽기 기록 (KB) | 묵상 노트 (KB) | 하이라이트 (KB) | **총 증가량 (KB)** |
|------|----------------|----------------|-----------------|--------------------|
| **1일** | 0.1 | 0.5 ~ 2.0 | 0.15 | **~0.75 - 2.25** |
| **1년** | 36 | ~250 | 55 | **~340 KB** |
| **10년** | 360 | ~2,500 | 550 | **~3.4 MB** |

### 결론
- **10년 사용 시 전체 DB 크기 예측**: 12.42 MB (기본) + 3.4 MB (사용자) = **~15.8 MB**
- **데이터베이스 부담**: SQLite 특성상 15MB는 매우 작은 크기로, 성능 저하 우려 없음.

## 💾 백업/복구 (JSON Import/Export) 설계 제언

### 예상 백업 파일 크기
- **1년치 데이터**: JSON 포맷으로 약 **380 KB**
- **압축 적용 (gzip)**: 약 **100 KB** 내외 예상

### 권장 구현 방향
1. **전체 백업**: 데이터 크기가 매우 작으므로, 복잡한 범위 지정 없이 **전체 내보내기**를 기본으로 해도 충분함.
2. **전송 방식**: 이메일 첨부, 카카오톡 전송 등이 충분히 가능한 가벼운 크기.
3. **구조 예시**:
```json
{
  "version": "1.0",
  "exported_at": "2026-01-05T14:55:00Z",
  "data": {
    "reading_logs": [...],
    "notes": [...],
    "highlights": [...]
  }
}
```
