# Release Notes - v1.2.0

> **배포일**: 2026-01-08  
> **테마**: "쾌적하고 친절한 성경 읽기 경험 (UX Polish)"

## 🚀 주요 신규 기능

### 1. 구절 클릭 다중 옵션 팝업
- 성경 구절을 클릭하면 즉시 **하이라이트, 메모 작성, 인용 복사**를 선택할 수 있는 플로팅 메뉴가 나타납니다.
- **지능형 UI**: 이미 하이라이트된 구절은 자동으로 '취소' 버튼으로 전환되어 관리가 편리해졌습니다.
- **자동 인용**: 메모 작성 시 클릭한 구절의 참조(`[책 장:절]`)가 입력창에 자동으로 삽입됩니다.

### 2. 묵상 양식 (Reflection Forms)
- 노트 에디터 상단에 **'묵상 양식'** 버튼이 추가되었습니다.
- 클릭 한 번으로 핵심 질문 가이드를 삽입하여, 무엇을 써야 할지 고민되는 순간을 도와줍니다.

### 3. 스마트 초기 말씀 로드
- 이제 앱을 켜면 무조건 말라기 1장이 아닌, **내가 마지막으로 읽었던 구절의 다음 장**을 자동으로 찾아 보여줍니다.
- 말씀 읽기의 연속성이 크게 향발되었습니다.

## 🛠️ 개선 및 보안 사항

- **자정 세션 만료 정책**: 매일 자정에 세션이 만료되도록 설정하여 보안을 강화하고, 매일 새롭게 접속하는 건강한 묵상 습관을 독려합니다.
- **데이터 저장 표준화**: 데이터베이스 저장 경로를 `server/data/`로 통합하여 데이터의 안정성과 가시성을 확보했습니다.
- **인증 핸들링**: 세션 만료 시 빈 화면이 아닌 로그인 페이지로 자연스럽게 안내하도록 에러 처리를 보강했습니다.
- **버그 수정**: 책을 변경했음에도 이전 책의 장 번호가 남아 로딩 에러가 발생하던 현상을 해결했습니다.

# Release Notes - v1.2.1 (Hotfix)

> **배포일**: 2026-01-08  
> **테마**: "백업 기능 긴급 패치"

## 🐛 버그 수정

### 백업(데이터 내보내기/가져오기) 기능 오류 해결
v1.2.0에서 발생한 백업 기능 오류를 수정했습니다.

**원인 분석:**
1. **localhost 하드코딩** - 배포 환경(Fly.io)에서 요청 실패
2. **인증 쿠키 미전송** - 401 Unauthorized 에러 발생
3. **saveDB() 미호출** - 데이터 import 후 영속성 미보장

**수정 내용:**
- `Settings.jsx`: localhost URL → 상대 경로(`/api/backup/*`) 변경
- `Settings.jsx`: `credentials: 'include'` 추가로 인증 쿠키 전송
- `backup.js`: import 후 `saveDB()` 호출 추가
