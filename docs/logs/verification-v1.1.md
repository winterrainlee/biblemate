# BibleMate v1.1.0 검증 로그

**검증일**: 2026-01-06  
**검증자**: 사용자 (개발자)  
**환경**: 
- 로컬: Node.js (Windows), Vite
- 클라우드: Fly.io (Docker Container / Linux)
- 인증 테스트용 환경변수: `ACCESS_PASSWORD=0000`

---

## 검증 결과 요약

v1.1.0의 모든 핵심 기능(백업, UI, 보안, 배포)이 **정상 작동**하는 것을 확인했습니다.

| 기능 | 상태 | 비고 |
|------|------|------|
| 데이터 백업/복구 | ✅ 통과 | JSON 직렬화 및 트랜잭션 복구 확인 |
| 대시보드 토글 | ✅ 통과 | localStorage 상태 유지 확인 |
| 암호 보호 (Auth) | ✅ 통과 | 환경변수에 따른 조건부 활성화 및 세션 유지 확인 |
| 클라우드 배포 | ✅ 통과 | Fly.io 빌드 성공 및 영구 볼륨 데이터 유지 확인 |

## 상세 검증 내용

### 1. 액세스 암호 보호 (Access Security)
- **로그인 시나리오**:
  - 잘못된 암호 입력 시: "Incorrect password" 오류 메시지 표시 확인.
  - 올바른 암호(`0000`) 입력 시: 인증 성공 및 메인 화면 진입 확인.
- **세션 유지**: 
  - 브라우저 종료 후 재접속 시 로그인 상태 유지 확인 (세션 쿠키 유효기간 내).
- **로그아웃**:
  - 설정 페이지 하단 로그아웃 버튼 클릭 시 즉시 로그인 화면으로 리다이렉트 확인.
- **로컬 호환성**:
  - `ACCESS_PASSWORD` 환경변수 제거 시 암호 절차 없이 바로 접속되는 '개발 편의성' 유지 확인.

### 2. Fly.io 클라우드 배포 및 지속성
- **빌드 파이프라인**: 
  - Docker 3단계 빌드를 통해 성경 원본 데이터로부터 DB가 성공적으로 생성됨을 로그로 확인.
- **데이터 지속성 (Persistence)**:
  - `fly deploy`를 통해 앱 재배포 후에도 기존에 작성된 '노트'와 '하이라이트'가 유실되지 않고 유지됨을 확인 (Volume 마운트 정상 작동).

### 3. 백업 및 UI 최적화
- **백업 파일**: 다운로드된 JSON 파일이 v1.1.0 규격(`version`, `exported_at`, `data`)을 준수함.
- **모바일 UI**: `BibleSelector` 가시성이 개선되어 한 화면에서 책과 장을 동시에 선택하기 훨씬 수월해짐.

## 기술 검토 내역

### 보안 (Security)
- `HttpOnly` 쿠키를 사용하여 XSS로부터 세션 토큰 보호.
- `sameSite: 'strict'` 옵션으로 CSRF 공격 방어.

### 인프라 (Infrastructure)
- Docker 이미지 크기 최적화 (Alpine Linux 사용).
- 볼륨 마운트 경로 `/app/server/db-data` 권한 및 자동 생성 로직 검증 완료.
