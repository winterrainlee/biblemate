# BibleMate 📖

> **Current Version: v2.3.3** (구절 묵상 기반 읽음 자동 표시)

매일 성경을 읽고 묵상을 기록하며 영적 성장을 돕습니다. 웹에서 작동하는 웹앱입니다.
Fly.io를 통해 24시간 어디서나 접속할 수 있으며, 암호 보호 기능을 통해 나만의 묵상을 안전하게 관리할 수 있습니다.

## 주요 기능 ✨

### 📖 말씀 읽기 (Reading)
- **3-Column 레이아웃**: 성경 본문과 구절별 묵상을 한눈에 볼 수 있는 데스크톱 최적화 뷰를 제공합니다. 성경책의 양쪽 여백에 메모하던 것처럼, 양쪽 사이드바에 내 마음 속 깊이 와닿은 구절의 묵상을 남겨 보세요.
- **다중 역본 지원**: 기존의 개역한글(KRV) 및 WEB 역본에 BBE(Bible in Basic English)가 추가되었습니다. 보다 쉬운 영어로 성경을 읽을 수 있습니다.
- **구절별 묵상 표시**: 묵상을 남긴 구절은 본문에 **빨간 밑줄**과 **📝 아이콘**으로 표시됩니다.
- **구절 다중 선택**: 클릭을 통해 여러 구절을 한 번에 선택하여 하이라이트하거나 묵상을 남길 수 있습니다.

### 📝 묵상일지 (Journal)
- **독립된 일지 모드**: 성경 읽기와 묵상 기록을 분리하여 묵상에 집중할 수 있는 전용 페이지를 제공합니다.
- **묵상 복사**: 당일 묵상(구절별 묵상, 자유 묵상, 오늘의 기도)을 1클릭으로 클립보드에 복사합니다.
- **자유 묵상**: 구절과 별개로 묵상을 남기고 싶을 경우, 자유 묵상 공간을 활용해 보세요.
- **오늘의 기도**: 묵상 후 기도를 남길 수 있습니다.
- **날짜 탐색 연동**: 성경 읽기 화면에서 읽음 표시를 클릭하면 해당 날의 묵상일지로 바로 이동합니다.

### 📊 진도 및 통계 (Tracking)
- **전체 요약**: 이번 달 읽은 분량, 작성한 묵상 수 등을 대시보드에서 한눈에 파악합니다.
- **읽기 진도표**: 구약과 신약의 전체 읽기 진행률(%)을 시각적 바 차트로 제공합니다.
- **유연한 달력**: 과거의 읽기 기록과 묵상을 손쉽게 찾아갈 수 있습니다.

### 📦 데이터 관리 (Backup & Restore)
- **서버 설정 동기화**: 서체 설정, 형광펜 이름 등이 서버에 저장되어 여러 기기에서 동일한 환경을 유지합니다.
- **데이터 백업/복구**: 모든 기록을 JSON 파일로 안전하게 내보내고 다시 가져올 수 있습니다. 

### ⚙️ 사용자 경험 (UX)
- **서재형 라이트/다크 모드**: 따뜻한 종이와 잉크, 밤의 서재를 닮은 Candlelight 테마를 지원합니다.
- **모바일 묵상 흐름**: 모바일에서는 compact 성경 헤더, 구절 액션 바텀시트, 전체 화면 묵상 작성, 하단 읽기 액션 바로 한 손 조작을 지원합니다.
- **커스텀 형광펜**: 4가지 형광펜에 나만의 이름(관찰, 적용 등)을 붙여 체계적으로 관리합니다.
- **본문 글꼴 및 가독성**: 명조, 고운바탕, 고딕 중 원하는 성경 본문 서체를 선택하고 글자 크기를 조절하여 최적의 독서 환경을 만듭니다.

## 기술 스택 🛠️

- **Frontend**: React, Vite, React Router
- **Styling**: Vanilla CSS (CSS Variables, Responsive Flex/Grid)
- **Backend**: Node.js, Express
- **Database**: SQLite (`sqlite3`, `sql.js`)
- **Key Libraries**: `date-fns`, `lucide-react`

## 설치 및 실행 🚀

### 1. 프로젝트 설정
```bash
# 레포지토리 복제
git clone <repository-url>
cd bible-reading-mate

# 패키지 설치
npm install
cd client && npm install
cd ../server && npm install
```

### 2. 데이터베이스 설정
```bash
npm run import-bible
```

### 3. 개발 서버 실행
```bash
npm run dev
```

### 성경 데이터 저작권
> ✅ **BibleMate는 저작권 법을 준수하며, 퍼블릭 도메인 또는 허가된 역본만 사용합니다.**

| 역본 | 저작권 상태 | 비고 |
|------|------------|------|
| **개역한글 (KRV)** | ✅ 저작권 준수 | 대한성서공회 발행, 본문 동일성 유지 조건 준수 |
| **WEB (영어)** | ✅ Public Domain | World English Bible (2020 완성), 현대 영어 |
| **BBE (영어)** | ✅ Public Domain | Bible in Basic English (1965), 쉬운 영어(1,000단어) |
