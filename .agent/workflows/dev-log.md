# Dev-Log 워크플로우

버전별 개발 로그를 생성하고 기능 구현 시마다 내용을 추가하는 워크플로우입니다.

## 1단계: 로그 파일 확인/생성
1. `docs/03-logs/dev-log-v{버전}.md` 파일이 있는지 확인합니다.
2. 없다면 아래 템플릿으로 새로 생성합니다:

```markdown
# 개발 로그 - v{버전}

## 개요
- **버전**: v{버전}
- **기간**: {시작일} ~ 진행 중
- **목표**: (한 줄 요약)
- **주요 변경**:
    - (기능/버그 수정 목록)

## 변경 내역

### {날짜}
#### [Feature/Bug Fix/Refactor] {제목}
- `{파일명}`: 변경 내용 설명

## 이슈 및 해결
- **이슈**: (문제 상황)
- **원인**: (근본 원인)
- **해결**: (해결 방법)

## 검증 결과
- [ ] npm run dev 실행 확인
- [ ] (추가 검증 항목)

## 다음 계획
- (다음 작업 목록)
```

## 2단계: 내용 추가
1. 기능 구현이 완료될 때마다 "변경 내역" 섹션에 항목을 추가합니다.
2. 날짜별로 그룹화하고, [Feature], [Bug Fix], [Refactor] 등 태그를 붙입니다.
3. 변경된 파일명과 구체적인 변경 내용을 기록합니다.

## 3단계: 이슈 기록
- 작업 중 발생한 이슈와 해결 방법을 "이슈 및 해결" 섹션에 기록합니다.
- 같은 실수를 반복하지 않도록 원인과 해결책을 명확히 작성합니다.

## 사용 시점
- `/feature` 워크플로우 실행 시: 해당 버전의 dev-log 파일 생성/확인
- 기능 구현 완료 시: 변경 내역 추가
- `/pr` 워크플로우 실행 전: dev-log 최종 업데이트 확인
